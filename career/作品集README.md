## 简历写法（直接可用，按JD删改）

### 项目段1：数据洞察 Agent（AI应用作品）

> **数据洞察 Agent（个人项目）** 独立开发
> 基于真实电商订单数据（54万行）构建的自然语言数据分析Agent：用户用中文提问，Agent自动选择分析工具、执行pandas计算、对结果独立复算校验后输出结论、数据表与可视化图表。
> - 设计工具层8个工具（数据画像/聚合/趋势/RFM/图表），统一结构化返回与错误反馈，支撑LLM稳定调用
> - 实现verify核验机制：结论输出前用独立代码路径复算，拦截模型计算错误；全程工具调用留痕可审计
> - 建立固定评估集（15题），标准答案用独立实现离线计算，改代码必回归
> - 提供Streamlit界面：数据上传、对话分析、会话留痕、报告一键导出
> 技术栈：Python / pandas / Function Calling / pyecharts / Streamlit

### 项目段2：电商经营分析案例（业务作品）

> **电商经营分析：客户分层与增长拆解（个人项目）**
> 基于54万行真实电商订单（UCI Online Retail）完成从数据清洗到经营建议的完整分析：
> - 清洗口径显性化：识别退货单（负数量+C开头发票）、缺失客户ID占比25%、剔除不完整月份，全程口径可追溯
> - RFM分层发现26%客户贡献69%GMV，识别「重要挽留」层约£48万收入风险敞口并给出召回优先级建议
> - 拆解增长结构：旺季备货节奏（9-11月）、订单量驱动（客单价平稳）、海外市场第二曲线（荷兰/爱尔兰/德国）
> - 主动暴露数据局限：缺失周六订单、邮费混入商品榜、均值被大户拉高等5个坑，先验数据再下结论
> 技术栈：pandas / RFM模型 / pyecharts

## 使用注意

1. 简历上写「个人项目」如实，不要写公司项目
2. 两个项目讲的时候**先讲业务结论再讲技术**，面试官多数是业务方
3. 数据集来源（UCI）要能脱口而出，「54万行/2010-2011/英国批发电商」三个数记住
4. 面试前把 `电商数分面试题库.md` 的口径速查过一遍——口径答错最伤
