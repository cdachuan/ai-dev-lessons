## 一、高频技术题（20道）

### SQL 窗口函数类

**1. 用 SQL 查每个品类销售额 Top 3 的商品**
- 考察点：窗口函数分组排序
- 答题要点：`ROW_NUMBER() OVER(PARTITION BY category_id ORDER BY gmv DESC)`；注意并列情况用 `RANK()` 还是 `DENSE_RANK()` 要说清楚

**2. 计算每天的用户留存率（次日/7日/30日）**
- 考察点：留存分析经典 SQL
- 答题要点：先取每个用户首次访问日期，再 LEFT JOIN 同用户 N 天后的访问记录，最后 GROUP BY 首访日期算比率

**3. 查连续登录 3 天以上的用户**
- 考察点：窗口函数 + 日期处理
- 答题要点：`ROW_NUMBER()` 对用户+日期排序，用日期减去排名得到分组标识，再 HAVING COUNT(*) >= 3

**4. 计算每个用户的月度消费总额及环比增长率**
- 考察点：窗口函数 LAG
- 答题要点：先聚合月度消费，再用 `LAG(month_gmv) OVER(ORDER BY month)` 取上月值算环比

**5. 查找出同一用户购买过不同品类的订单对**
- 考察点：自连接 + 窗口函数
- 答题要点：自连接按 user_id 配对，筛选品类不同的组合

---

### SQL 业务查询类

**6. 统计每个用户的复购率（购买 ≥2 次的用户占比）**
- 考察点：复购指标计算
- 答题要点：先算每个用户订单数，再用 `SUM(CASE WHEN order_cnt >= 2 THEN 1 ELSE 0 END) / COUNT(DISTINCT user_id)`；口径争议：统计周期需明确

**7. 计算每个品类的转化率（下单人数/浏览人数）**
- 考察点：转化漏斗计算
- 答题要点：分别聚合浏览和下单用户数，注意去重；分母是否含未浏览直接下单的用户需讨论

**8. 找出 7 天内未活跃的高价值用户（RFM 中 R>7 且 M 排前 20%）**
- 考察点：RFM 模型 SQL 实现
- 答题要点：先算每个用户最近一次购买距今天数和累计金额，用 `PERCENTILE_CONT` 或子查询取 Top 20% 分位线

**9. 统计每个品类的 GMV、订单量、客单价，并按 GMV 降序排列**
- 考察点：基础聚合 + 多指标
- 答题要点：`SUM(amount) AS gmv, COUNT(DISTINCT order_id) AS order_cnt, gmv/order_cnt AS avg_order_value`

**10. 查找同一商品在不同地区销量差异超过 3 倍的 SKU**
- 考察点：分组聚合 + HAVING 过滤
- 答题要点：按 SKU+地区聚合销量，取 MAX/MIN，HAVING 比值 > 3

### Pandas / Python 类

**11. 用 Pandas 实现 RFM 分层**
- 考察点：数据处理 + 分箱
- 答题要点：`pd.cut()` 对 R/F/M 分箱（通常 3-5 档），再拼接标签得到 RFM 分层

**12. 如何处理订单数据中的缺失值和异常值？**
- 考察点：数据清洗
- 答题要点：缺失值看业务含义决定填充/删除；异常值用 IQR 或 3σ 原则识别，结合业务判断保留或剔除

**13. 实现两表关联时遇到重复 key 怎么办？**
- 考察点：Merge 操作细节
- 答题要点：先检查重复原因（一对多是否合理），用 `drop_duplicates` 或调整关联键；`indicator=True` 检查匹配情况

**14. 用 Pandas 写一个同比/环比计算函数**
- 考察点：时间序列处理
- 答题要点：设日期索引，`.shift(1)` 取上期，`.pct_change()` 算增长率

**15. 处理高基数类别特征（如商品ID）的编码方式有哪些？**
- 考察点：特征工程
- 答题要点：One-Hot（稀疏高维）、Target Encoding（均值编码）、频率编码、Embedding（深度学习场景）

### 指标口径类

**16. GMV 的口径争议有哪些？**
- 考察点：指标定义严谨性
- 答题要点：含不含退款/售后？含不含优惠券金额？含不含运费？统计口径是下单时间还是支付时间？面试时主动说清楚你假设的口径

**17. 客单价（AOV）的计算方式有几种？**
- 考察点：指标多义性
- 答题要点：①GMV/下单用户数 ②GMV/订单数 ③GMV/支付用户数；不同口径含义不同，业务场景决定用哪个

**18. 什么是"有效订单"？口径怎么定？**
- 考察点：业务理解
- 答题要点：通常指已支付且未退款的订单；但"有效"定义因业务而异，面试时反问确认口径是加分项

**19. 转化漏斗各阶段怎么定义？**
- 考察点：漏斗分析
- 答题要点：曝光→点击→浏览→加购→下单→支付；每步定义需明确（如"浏览"是停留 > 3s 还是 > 页）

**20. 留存率的统计周期不同，业务含义有何区别？**
- 考察点：留存分析深度
- 答题要点：次日留存看产品粘性，7日留存看中期留存，30日留存看长期价值；电商大促后重点关注次日/3日留存

---

### A/B 测试基础

**21. A/B 测试前需要做哪些准备？**
- 考察点：实验设计
- 答题要点：①明确假设和指标（主指标+护栏指标）②样本量估算（MDE、显著性水平、功效）③分流方案（用户/设备/订单）④实验周期（避开大促）

**22. p 值 < 0.05 就一定上线新版本吗？**
- 考察点：统计显著 vs 业务显著
- 答题要点：不一定。要看①效果量（lift 太小无业务价值）②样本量是否充足 ③是否有多重比较问题 ④护栏指标是否恶化

**23. 实验周期太短会有什么问题？**
- 考察点：实验陷阱
- 答题要点：①新奇效应未消退 ②周期性波动未覆盖 ③样本量不足导致统计功效低

## 二、电商业务场景题（10道）

**1. 本周销售额比上周下降 10%，怎么拆解？**
- 拆解框架：
  - 流量侧：UV 下降？来源渠道变化？流量质量变化？
  - 转化侧：浏览→下单转化率？各环节漏斗？
  - 客单价侧：品类结构变化？促销力度变化？
  - 外部因素：节假日？竞品活动？行业大盘？

**2. 怎么定义一个"爆款"商品？**
- 评估维度：
  - 销量维度：品类销量排名 Top X%
  - 增速维度：环比增长率超阈值
  - 流量维度：自然搜索占比高（非纯付费拉动）
  - 持续性：热销天数 > N 天
  - 综合评分：可设计加权公式

**3. 大促期间转化率比日常低，分析可能原因？**
- 分析方向：
  - 流量质量：大量优惠导向用户，购买意愿弱
  - 页面体验：大促页面复杂，决策成本高
  - 价格锚点：原价虚高，用户对折扣敏感度下降
  - 库存问题：热销 SKU 断货

**4. 某品类 GMV 增长但利润下降，怎么分析？**
- 拆解角度：
  - 品类结构：高毛利品类占比下降
  - 促销成本：满减/优惠券使用率上升
  - 退货率：退货率上升侵蚀利润
  - 物流成本：偏远地区订单占比上升

**5. 如何评估一次营销活动的效果？**
- 评估框架：
  - 直接效果：活动期间 GMV/订单量/新客数
  - 拉新效果：新用户获取成本（CAC）、次日留存
  - 品牌效果：搜索指数、社媒提及量
  - 长期价值：活动用户 LTV 对比自然用户
  - 成本核算：ROI = 活动增量利润 / 活动总成本

**6. 如何搭建一个用户分层体系？**
- 搭建思路：
  - RFM 模型：按最近购买、购买频次、消费金额分层
  - 生命周期：新客→活跃→沉默→流失
  - 价值分层：高价值/中价值/低价值/负价值（薅羊毛）
  - 行为标签：品类偏好、价格敏感度、促销敏感度

**7. 怎么分析"加购不下单"的原因？**
- 分析路径：
  - 价格因素：对比竞品价格、历史价格
  - 库存因素：缺货/预售等待
  - 体验因素：结算流程复杂、支付方式缺失
  - 犹豫心理：缺少评价/销量背书

**8. 新品冷启动阶段，数据分析师能做什么？**
- 支持方向：
  - 流量分配：AB测试不同曝光策略
  - 标签建设：基于历史数据预测潜力
  - 竞品分析：定位差异化卖点
  - 迭代优化：收集早期用户反馈迭代

**9. 退货率异常升高，如何排查？**
- 排查步骤：
  - 维度拆解：品类/SKU/地区/时间段
  - 物流因素：配送时长、破损率
  - 商品因素：质量投诉、描述不符
  - 用户因素：恶意退货、冲动消费

**10. 如何预测下个月的 GMV？**
- 预测方法：
  - 趋势外推：历史同比/环比增长率
  - 多因素模型：流量×转化率×客单价
  - 机器学习：时间序列（Prophet/LSTM）+ 特征工程（大促标记、节假日、营销投入）
  - 修正：结合业务判断调整预测值

## 三、AI + 数分交叉题（5道）

**1. 怎么用 LLM 辅助数据分析？**
- 应用场景：
  - 自然语言转 SQL：用户描述需求，LLM 生成查询
  - 报告自动生成：从数据洞察生成文字总结
  - 异常检测：LLM 辅助解读异常原因
  - 数据字典查询：快速检索指标口径

**2. LLM 生成的 SQL 怎么保证正确？**
- 验证方案：
  - 口径对齐：将指标定义文档作为上下文注入
  - 验证集：准备 50+ 标准 SQL 问题对，定期评估准确率
  - 人工审核：关键查询需人工 review
  - 执行前 explain：检查执行计划是否合理

**3. 怎么评估 LLM 辅助分析的质量？**
- 评估维度：
  - 准确性：生成结果 vs 标准答案
  - 完整性：是否覆盖所有分析维度
  - 可解释性：是否给出分析逻辑
  - 效率提升：相比人工节省多少时间

**4. Agent 架构中，数据分析 Agent 怎么设计？**
- 架构要点：
  - 规划层：将复杂问题拆解为子任务
  - 工具层：SQL执行器、可视化、统计检验
  - 验证层：结果合理性校验（如转化率不应 > 100%）
  - 记忆层：保存历史分析结论，避免重复

**5. 用 AI 做数据分析有哪些风险？**
- 风险点：
  - 幻觉问题：LLM 编造不存在的指标/数据
  - 口径偏差：不同业务对同一指标定义不同
  - 过度依赖：忽视数据背后的业务逻辑
  - 数据安全：敏感数据泄露给 LLM 服务
  - 缓解措施：建立验证机制、权限控制、审计日志

## 附：核心指标口径速查

| 指标 | 常见口径 | 争议点 |
|------|----------|--------|
| GMV | 下单金额（含未支付） | 是否含退款？含优惠券？ |
| 客单价 | GMV / 下单用户数 | 还是 GMV / 订单数？ |
| 复购率 | 购买 ≥2 次用户占比 | 统计周期（30天/90天/自然年） |
| 次日留存 | 次日回访用户 / 当日新增 | 是否含 App 启动但无行为？ |
| 转化率 | 下单人数 / 浏览人数 | 分母是否含未浏览直接下单？ |
| RFM 的 R | 最近一次购买距今天数 | "购买"是下单还是支付？ |
