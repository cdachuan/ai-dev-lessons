📈 画图：用 matplotlib 可视化数据

第 0020 课 · 应用篇·三 实践课

🎯 本课目标：学会用 matplotlib 把 pandas 算好的数字变成图。上一课你学会了「算指标 + 下结论」，今天加一步：把结论画出来。

为什么要画图

上一课你算出了台区用电波动指标，用 AI 下了结论。但结论是这样的：

台区T07，波动600kWh
台区T03，波动190kWh
台区T12，波动85kWh
...

你自己能看懂，但给领导看呢？给同事看呢？一张图胜过十行数字——领导看 3 秒图就能抓住重点，看 3 分钟表格可能还没找到关键信息。

📊 matplotlib 是 Python 最经典的画图库。几乎所有数据分析的图都靠它。你不需要记住所有参数，只需要知道画什么图、怎么让 AI 帮你写代码。

最简单的图：3 行代码

# 安装（如果还没装）：pip install matplotlib
import matplotlib.pyplot as plt

plt.plot([1, 3, 2, 5, 4])
plt.show()

就这？就这。plt.plot() 画线，plt.show() 弹出窗口显示。这就是 matplotlib 的核心模式：画 → 显示。

三种最常用的图

数据分析中 90% 的场景，用这三种图就够了：

图类型函数什么时候用举例
折线图plt.plot()看趋势（随时间变化）台区日用电量的变化曲线
柱状图plt.bar()比大小（不同类别之间）各台区波动幅度对比
直方图plt.hist()看分布（数据集中在哪）所有台区平均电量的分布
💡 选图口诀：看趋势用线，比大小用柱，看分布用直方。记不住没关系，跟 AI 说你想看什么，它会帮你选。

中文标签的坑

matplotlib 默认不支持中文，标题和坐标轴写了中文会显示成方框 □□□。加上这两行就行：

plt.rcParams['font.sans-serif'] = ['SimHei']        # Windows 用黑体
plt.rcParams['axes.unicode_minus'] = False  # 修复负号显示

每次画图前加上这两行，或者让 AI 帮你加。这是新手最常踩的坑，没有之一。

让 AI 帮你画图

延续上一课的模式：你描述需求，AI 写代码。你跟 AI 说：

"我用 pandas 算出了 10 个台区的用电波动幅度，存在 result 这个 DataFrame 里，索引是台区编号，列名是'波动幅度'。帮我画柱状图，从大到小排列，加上标题和坐标轴标签。"

AI 会生成完整代码，你跑一下就能看到图。

完整示例：台区用电波动可视化

把上一课的算好的数字，变成一张能放进报告的图：

import matplotlib.pyplot as plt

# ① 解决中文显示（必加）
plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

# ② 取波动最大的 10 个台区（假设 result 是上一课算好的）
top10 = result.sort_values('波动幅度', ascending=False).head(10)

# ③ 画柱状图
plt.figure(figsize=(10, 5))              # 图的大小
plt.bar(top10.index, top10['波动幅度'])    # 画柱子
plt.title('台区用电波动幅度 Top 10')       # 标题
plt.xlabel('台区编号')                   # X轴标签
plt.ylabel('波动幅度 (kWh)')             # Y轴标签
plt.xticks(rotation=45)                      # X轴标签转45度

# ④ 保存图片（必须在 show 之前！）
plt.tight_layout()                          # 自动调整布局
plt.savefig('台区波动.png', dpi=150)     # 存成图片
plt.show()
⚠️ 最常见的坑：plt.savefig() 必须在 plt.show() 之前调用。因为 show() 会清空画布，之后再 savefig 存出来的是空白图。

保存图片

plt.savefig('文件名.png') 把图存成文件，可以插到报告、PPT、邮件里。dpi=150 控制清晰度（150 够用，300 印刷级）。

三步走：算 → 判 → 画

上一课你学了两步走：pandas 算指标 → AI 下结论。今天加上第三步，变成完整的数据分析流水线：

步骤做什么用什么产出
① 算从原始数据算出指标pandas（AI 帮你写）一张表 / 几个数字
② 判基于数字判断异常/趋势AI 推理一段结论文字
③ 画把数字变成直观的图matplotlib（AI 帮你写）一张图

三步走是以后所有 AI 数据分析项目的骨架——算清楚、判明白、画好看。

🤔 小测

你用 pandas 算出了 10 个台区的用电波动幅度，想让领导一眼看出哪个台区波动最大。用哪种图最合适？

  1. 柱状图，比大小最直观
  2. 折线图，看趋势最清楚
  3. 饼图，看占比最合适
  4. 散点图，看关系最直接
