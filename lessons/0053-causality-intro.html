⚖️ 因果入门：相关 ≠ 因果与辛普森悖论

第 0053 课 · 选修线二 统计与实验 · 收官 · 预计 20 分钟

🎯 本课目标：建立数分的科学性防线——三个必须刻进本能的反射：找混杂变量、警惕幸存者偏差、分段复核辛普森。全部用你的真实数据演示。

一、混杂变量：相关系数 0.948 的真相

你的数据里，月度 GMV 与订单数相关系数 0.948——几乎完美相关。能说「订单多导致 GMV 高」吗？

📌 两者都是结果，不是因果：真正的原因是「旺季」——圣诞备货季（9-11月）同时推高订单量和 GMV。旺季来了 → 订单多 且 客单结构变化 → 两者齐涨。相关系数再高，也分不清「A导致B」还是「C同时导致A和B」。

观察性数据的通病：你控制不了谁被「处理」。买会员的用户本来就更活跃——你观察到的「会员更活跃」没法证明会员制有效。这就是为什么 A/B 测试（随机分流）是数分手里的因果王牌（52 课）。

二、辛普森悖论：分组全胜，合计反输

构造一个最小案例（数字已验证）：

版本群体访问转化转化率
A新客1000505.0%
老客4000802.0%
B新客40001604.0%
老客1000151.5%

分组内看：A 在新客 5%>4%、在老客 2%>1.5%，全胜。合计看：

版本总访问总转化合计转化率
A50001302.6%
B50001753.5%

A 全胜却总输——因为 B 的流量集中在高转化的新客群。这就是辛普森悖论：合计数据被「人群结构」污染。解法：看加权前的分组结论，问「人群结构是否可比」。52 课让你 A/B 分段复核，防的就是它。

三、幸存者偏差：高估 85% 的客户价值

真实数据实测：只看「11 月还在活跃」的客户，其全年人均消费 £3,392；全体客户只有 £1,838——高估 85%。

⚠️ 这个偏差无处不在：「我们的老用户满意度高」（不满意的早走了）、「爆款商品好评率高」（失望的人不写评论）、「名校毕业生都成功」（没成功的你看不到）。问自己：我没看到的样本去哪了？

四、数分的因果反射清单

  1. 看到强相关 → 先找混杂变量 C（什么同时推高 A 和 B？）
  2. 看到「X 用户表现更好」→ 先问自选择（是他们本来就好，还是 X 让他们好？）
  3. 看到合计结论 → 分段复核，查辛普森
  4. 看到漂亮的样本统计 → 问没出现的样本去哪了（幸存者）
  5. 真要因果结论 → 随机实验（A/B），或至少倾向得分/双重差分等准实验方法（P7 延伸）

动手任务（20 分钟）

  1. 算月度 GMV 与订单数的相关系数，对上 0.948；再画散点图，标出旺季月份。
  2. 复现幸存者偏差：对比「近期活跃客户」与「全体客户」的全年人均消费。
  3. 在 RFM 分层里找一个「自选择」例子：VIP 更活跃是会员制的效果吗？
  4. 用课文辛普森表做基础，改流量分配比例，看合计结论什么时候翻转。
🎯 本课核心结论：观察性数据只能提示相关，因果要靠随机化或额外的假设与论证。五个反射（混杂/自选择/分段复核/幸存者/上实验）是你区别于「会跑数的人」的核心素养——面试聊到任何业务数字，主动用它们审视一遍，层次立刻不同。

本课学了什么

  • ✅ 混杂变量：GMV 与订单数 0.948 的共同原因是旺季
  • ✅ 辛普森悖论：组内 A 全胜、合计 A 反输的构造与识别
  • ✅ 幸存者偏差：只看活跃客户，人均消费高估 85%（实测）
  • ✅ 随机化是王牌：A/B 测试是观察数据给不了的因果能力

运营说：「用了新推送的用户 7 日留存 60%，没用的人只有 40%，推送效果显著！」最该先问什么？

  1. p 值是多少？
  2. 这两组用户是怎么分的——是随机分的，还是「愿意接收推送」的用户本身就更活跃？
  3. 推送内容是什么？
  4. 把推送停了看看留存会不会掉
