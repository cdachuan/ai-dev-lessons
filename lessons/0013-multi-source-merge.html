🔗 搭一个多源信息合并工具

第 0013 课 · 实践课 工具篇·三

🎯 增量胜利：学完这课，你就能写一个脚本——把散在好几个文件里的信息（Excel 任务表 + 会议纪要 txt + 进度邮件）一次性喂给 AI，合并成一份统一周报。不用再来回切窗口拼凑了。

场景：信息散落在三个地方

作为项目助理，一份周报往往要从多个来源攒出来：

  • tasks.xlsx —— 任务进度表（谁在做什么、什么状态）
  • meeting.txt —— 上周例会的会议纪要
  • progress.txt —— 各方发来的进度反馈

以前的做法：三个文件挨个打开 → 复制粘贴 → 自己在脑子里合并 → 手写周报。今天的脚本把这件事变成一行命令：

$ python merge_sources.py 素材文件夹/

核心思路

和前两课一样是「读 → 组装 → 调 API」，唯一的新点是：读的不再是一个文件，而是一整个文件夹里的多个文件，还要按格式分别处理。

  1. 扫描文件夹 → 找出里面所有文件
  2. 按类型分派读取 → .xlsx 用 openpyxl，.txt 直接读文本
  3. 合并成一段大文字 → 每个来源打上标题，拼在一起
  4. 调 API 汇总 → 让 AI 综合所有来源，产出一份周报

新工具：pathlib 遍历文件夹

pathlib 是 Python 自带的库，用来优雅地处理文件路径。核心三招：

代码作用
Path("文件夹")把一个文件夹变成可操作的对象
folder.iterdir()遍历文件夹里的每个文件
p.suffix取文件后缀（如 .xlsx / .txt），用来判断类型

完整脚本

创建 merge_sources.py：

from openai import OpenAI
from openpyxl import load_workbook
from pathlib import Path
import sys

client = OpenAI(api_key="sk-你的密钥", base_url="https://api.deepseek.com")

# 1. 读 Excel → 转文字
def read_excel(path):
    wb = load_workbook(path)
    sheet = wb.active
    lines = []
    for row in sheet.iter_rows(values_only=True):
        if any(c is not None for c in row):
            lines.append(" | ".join(str(c) if c else "" for c in row))
    return "\n".join(lines)

# 2. 读 txt → 转文字
def read_text(path):
    return path.read_text(encoding="utf-8")

# 3. 扫描文件夹，按类型分派
folder = Path(sys.argv[1])
merged = ""
for p in folder.iterdir():
    if p.suffix == ".xlsx":
        content = read_excel(p)
    elif p.suffix == ".txt":
        content = read_text(p)
    else:
        continue                       # 跳过不认识的格式
    merged += f"\n\n===== 来源：{p.name} =====\n" + content

# 4. 调 API 综合汇总
messages = [
    {"role": "system", "content":
        "你是项目助理。下面是来自多个来源的项目信息。请综合所有来源，输出一份本周项目周报，包含：整体进展、风险与问题、下周计划。同一件事在不同来源里出现要合并，不要重复。要求简洁、不客套。"},
    {"role": "user", "content": f"请综合以下多源信息生成周报：\n{merged}"}
]
resp = client.chat.completions.create(model="deepseek-chat", messages=messages)

print("=" * 40)
print("📋 本周项目周报（自动合并生成）")
print("=" * 40)
print(resp.choices[0].message.content)

新知识点逐行拆解

代码新在哪儿
def read_excel(path):自定义函数。把「读 Excel」这段逻辑打包成一个可复用的函数，主流程调用它就行——代码更清爽
from pathlib import Path路径处理库（自带，不用装）。比手动拼字符串路径更安全
folder.iterdir()遍历文件夹，一个个把里面的文件拿出来
p.suffix == ".xlsx"按后缀判断类型，决定用哪个读取函数
===== 来源：{p.name} =====给每段内容打标题，让 AI 知道信息来自哪，方便它标注和去重
💡 关键设计：给每个来源打上「===== 来源：xxx =====」的分隔标题，是这个脚本的灵魂。AI 看到来源标签后，就能判断「这条进度在任务表和邮件里都提到了，合并成一条」，而不是傻乎乎地重复列两遍。

本课学了什么

  • ✅ 用 def 把重复逻辑封装成函数
  • ✅ pathlib.Path + iterdir() 遍历文件夹
  • ✅ 用 .suffix 按文件类型分派不同读取方式
  • ✅ 用「来源标签」组织多源信息，让 AI 智能合并去重

🤔 小测

脚本里为什么要给每段内容加「===== 来源：文件名 =====」这个标题？

  1. 纯粹为了好看
  2. 让 AI 知道信息来自哪个文件，方便标注来源和跨源去重
  3. openpyxl 要求必须这样写
  4. 不加会报错
