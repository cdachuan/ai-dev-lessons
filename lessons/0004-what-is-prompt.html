📝 第 4 课 · 什么是 Prompt？

2026-07-02 · 阅读约 4 分钟 · 术语表

你每天都在写 prompt，只是你不知道它叫这个名字。

🎯 今天学完你能做这件事：
在赫默（或其他 AI 工具）里，有意识地写出 system prompt + user prompt 的结构，让 AI 的输出质量明显提升。不再是「瞎问瞎答」，而是「精准指挥」。

Prompt 是什么？

Prompt（提示词）就是你给 AI 模型的输入指令——你说了什么、问了什么、要求了什么，那整段话就是 prompt。

还记得第 3 课 Hello World 代码吗？

messages = [
    {"role": "user", "content": "用一句话介绍你自己"}
]

这段代码里的 "用一句话介绍你自己"——这就是一个 prompt。

🔍 生活中的类比：你给下属布置任务时说的那段话就是 prompt。说清楚→做好；说模糊→做偏。AI 也一样，而且更加「字面理解」——它不会像人一样猜测你的潜台词。

Prompt 的两个层级：System vs User

在上面的代码里，messages 是一个列表（list），可以放多条消息。最常见的两种角色：

角色作用什么时候用
system 给 AI 设定身份、规则、约束（一次设定、整个对话生效） 对话开始时，设定「AI 的角色」
user 你的具体问题/任务（每次都可以不同） 每次提问时
💡 举个例子： 
messages = [
    {"role": "system", "content": "你是一个耐心的老师，用小学五年级能听懂的话解释概念。"},
    {"role": "user",    "content": "什么是区块链？"}
]
加上 system prompt 之后，AI 的回复会明显更简单、更口语化。试试在赫默里也这样用：
「你是一个耐心的老师……什么是区块链？」

即使不写代码，你在赫默里也能用这个技巧：在对话开头先打一句「请你扮演一个……然后回答我的问题」，效果等同于 system prompt。

为什么说「不会 prompt = 不会用 AI」？

Prompt 的质量，直接决定了 AI 输出的质量。如果把 AI 模型比作一个超级聪明但对背景一无所知的新员工，prompt 就是你给 TA 的任务说明——越清楚，结果越好。

记住这个公式：好输入 × 好模型 = 好输出。
坏输入 × 好模型 = 随机输出。

好 Prompt vs 坏 Prompt

❌ 模糊指令✅ 清晰指令
「帮我写个方案」 「帮我写一份 500 字的项目推广方案，目标受众是中小企业老板，语气专业但有温度」
「这个数据怎么说」 「我手上有 3 月份销售额 120 万，比 2 月涨了 15%。请写一段话给老板汇报，突出增长、不提绝对值」
「翻译这个」 「请将以下英文翻译成中文，保持专业术语不变，译文风格：简洁商务」

写好 Prompt 的三个要素

  1. 🎯 明确目标 —— 你想要什么结果？「总结这篇文章」vs「用三句话总结核心观点，每句不超过 20 字」
  2. 📋 提供上下文 —— AI 没有默认背景知识。你给它越多相关背景，答案越准。比如告诉它你的身份、受众、用途
  3. 📐 指定格式 —— 想要清单、表格、一小段文字、还是 Markdown？直接说出来

你今天学到的「增量胜利」🥇

打开赫默，试试这个 prompt 结构：

你是一个经验丰富的项目助理。
你用简洁的语言回答，每条不超过 3 句话。

请帮我……

先设定身份（system prompt 的效果），再说具体任务——你会发现回复质量明显提高。

❓ 小测

你想让 AI 扮演一个「翻译助手」，只输出中文翻译结果不解释。以下哪段 messages 写法正确？

  1. [{"role": "user", "content": "你是一个翻译助手，只输出中文翻译"}]
  2. [{"role": "system", "content": "你是一个翻译助手，只输出中文翻译"}, {"role": "user", "content": "translate: Hello world"}]
  3. [{"role": "assistant", "content": "你是一个翻译助手"}]
  4. [{"role": "prompt", "content": "翻译以下内容"}]
