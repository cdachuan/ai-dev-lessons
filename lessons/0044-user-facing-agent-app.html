一、为什么需要界面？

你的 43 课作品已经是一个完整的 Agent——但它运行在命令行里。面试官或 HR 想试用，你得让他 pip install 再 python main.py——大部分人会在这一步放弃。

一个简单的 Streamlit 界面，能让你的作品从「需要会 Python 才能用」变成「打开网页就能用」。

📌 Streamlit 是什么？一个 Python 库，让你用纯 Python 代码生成 Web 界面。不需要写 HTML/CSS/JS，几行代码就是一个可交互的页面。适合快速做 demo 和原型，不适合生产级产品——但对于求职作品，够了。

二、最小 Streamlit 页面（5 分钟跑通）

import streamlit as st

st.title("数据洞察 Agent")

uploaded_file = st.file_uploader("上传 CSV 文件", type=["csv"])
if uploaded_file:
    st.success(f"已上传: {uploaded_file.name}")

question = st.text_input("输入你的分析问题")
if st.button("开始分析") and question:
    st.info("正在分析...（这里调用 Agent）")
    # TODO: 接入 Agent 逻辑
    st.write("分析结果将显示在这里")

运行方式：

streamlit run app.py

浏览器自动打开 http://localhost:8501，一个可交互的页面就出来了。

三、从最小页面到完整产品

在最小页面基础上，加上 43 课的 Agent 逻辑：

import streamlit as st
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent))

st.title("数据洞察 Agent")
st.caption("上传 CSV → 自然语言提问 → Agent 自主分析 → 图表报告")

# 1. 文件上传
uploaded_file = st.file_uploader("上传 CSV/Excel 文件", type=["csv", "xlsx"])

if uploaded_file:
    tmp_path = Path("data") / uploaded_file.name
    tmp_path.parent.mkdir(exist_ok=True)
    tmp_path.write_bytes(uploaded_file.getvalue())
    st.success(f"已上传: {uploaded_file.name}")

    # 2. 数据画像
    if st.button("查看数据画像"):
        from agent.tools import profile
        result = profile()
        st.json(result)

    # 3. 会话记录
    if "history" not in st.session_state:
        st.session_state.history = []

    question = st.text_input("输入你的分析问题")

    if st.button("开始分析") and question:
        with st.spinner("Agent 正在分析..."):
            from agent.core import run_agent, save_trace
            try:
                answer, trace = run_agent(question)
                st.session_state.history.append({"q": question, "a": answer})
                st.markdown(answer)
                save_trace(question, answer, trace)
            except Exception as e:
                st.error(f"分析失败: {e}")

    # 4. 历史会话
    if st.session_state.history:
        st.subheader("历史会话")
        for item in reversed(st.session_state.history):
            st.markdown(f"**Q:** {item['q']}")
            st.markdown(f"**A:** {item['a']}")
            st.divider()

四、关键设计决策

决策选择理由
用什么做界面Streamlit纯 Python，5 分钟出原型，求职作品够用
文件存哪本地 data/ 目录简单直接，不用配云存储
会话存哪st.session_state重启会清空，但对 demo 来说够了
报告怎么下载st.download_button一行代码，用户点一下就下载

五、动手任务：跑通一个最小 Streamlit 页面

  3. 运行 streamlit run app.py，浏览器会自动打开。
