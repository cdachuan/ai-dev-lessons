🎯 本课目标：让你的求职作品从「本地能跑」变成「别人能试用、可部署、有工程规范」——配置管理、日志、评估集、成本记录、监控、部署路径。这是 P6 的收尾，也是你简历上最硬的一行。

一、为什么工程化是最后一步？

43-44 课你已经做出了一个能跑、有界面的作品。但它还差「最后一公里」：

问题现状工程化后
API Key 怎么管？写死在代码里环境变量，不出代码
出错了怎么排查？print 看运气日志文件，分级记录
换了数据还能用吗？不确定评估集自动验证
花了多少钱？不知道成本记录，每次调用计费
别人怎么试用？让他装 Python一键部署，打开链接就能用

二、六项工程化清单

1. 配置管理

所有可变的东西（API Key、数据路径、模型名称、步数上限）都放到配置文件或环境变量里，不要写死在代码中。

# .env（不进 git）
DEEPSEEK_API_KEY=sk-xxx
DATA_FILE=data/orders.csv

# config.py（代码读取配置）
import os
API_KEY = os.environ.get("DEEPSEEK_API_KEY")
MAX_STEPS = int(os.environ.get("MAX_STEPS", 8))

2. 日志记录

用 Python 的 logging 模块替代 print——分级、带时间戳、可写文件。

import logging
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    handlers=[
        logging.FileHandler("logs/agent.log"),
        logging.StreamHandler()
    ]
)
logger = logging.getLogger(__name__)

logger.info("开始分析: %s", question)
logger.warning("结果为空，触发重试")
logger.error("API 调用失败: %s", e)

3. 评估集

43 课你已经写了 3 个评估问题。现在把它扩展成每次部署前自动跑一遍的回归测试。

# 部署前跑一遍
python -m tests.eval
# 输出：7 通过 / 0 失败 → 可以部署

4. 成本记录

每次 Agent 调用记录 token 用量和费用——面试官会问「你这个作品跑一次花多少钱？」

# 在 run_agent 里记录
usage = resp.usage.total_tokens
cost = usage * 0.000001  # 按模型定价估算
logger.info("本次消耗 %d tokens, 约 $%.4f", usage, cost)

5. 监控与优雅降级

API 挂了怎么办？网络超时怎么办？要优雅降级，不能直接崩。

try:
    answer, trace = run_agent(question)
except RuntimeError as e:
    st.error(f"服务暂时不可用: {e}")
    logger.error("Agent 运行失败: %s", e)

6. 部署路径（阶梯式，呼应 36 课）

三级阶梯部署

阶梯1：0 元可复现仓库（当前阶段）
  → GitHub 仓库 + README + 示例数据
  → 别人 clone 下来就能跑
  → 简历价值：证明你做了什么

阶梯2：免费托管平台
  → Streamlit Cloud（免费，一键部署）
  → GitHub Pages（静态页面）
  → 别人点链接就能试
  → 简历价值：证明别人能用

阶梯3：国内云（有成本，求职加分）
  → 阿里云/腾讯云 9.9 元学生机
  → 正式域名 + HTTPS
  → 生产级部署
  → 简历价值：证明你会部署
📌 阶梯1价值最高：0 元、可复现、README 完整——这是面试官最看重的。他会 clone 你的仓库，看代码结构、看 README、跑 selftest。不需要花钱部署，仓库本身就是作品。

三、动手任务：写一份作品部署 Checklist

  1. 配置管理：确保所有 API Key 都用环境变量，不出现在代码里。
  2. 日志：把所有 print 替换成 logging，加一个 logs/ 目录。
  3. 评估集：跑 python -m tests.eval，确认全部 PASS。
  4. README：补全「快速开始」「架构说明」「技术栈」三个板块。
  5. Git：加 .gitignore（排除 .env / logs/ / __pycache__/），提交到 GitHub。
  6. 截图：跑一次 Agent，截图放进 README 的「效果展示」部分。
⚠️ 部署前自检清单：
  • 代码里没有 API Key？
  • selftest 全部 PASS？
  • README 别人能看懂？
  • .gitignore 排除了敏感文件？
  • 示例数据包含在仓库里？
五条全过，才算「可部署」。
