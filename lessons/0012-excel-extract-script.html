📊 搭一个 Excel 数据提取脚本

第 0012 课 · 2026-07-21 · 实践课 工具篇·二

🎯 增量胜利：学完这课，你就能写一个脚本——扔一个 Excel 文件进去 → AI 自动读出问题、分析状态、生成摘要。再也不用手动一条条看了。

场景：项目任务跟踪表

作为项目助理，你手头可能有一个这样的 Excel 表格（比如叫 project_tasks.xlsx）：

任务名负责人截止日期状态
需求文档编写张三2026-07-25进行中
UI 设计评审李四2026-07-20已完成
后端 API 开发王五2026-08-01未开始
测试用例编写赵六2026-07-28进行中

你每天可能需要：

  • 快速知道「今天有哪些截止的任务？」
  • 汇总「每个负责人手上有几件事？状态如何？」
  • 找出「哪些任务快要逾期了？」

以前的做法：打开 Excel → 一条条看 → 用自己的脑子汇总 → 打字写汇报。费时间，还容易漏。

今天的脚本，把这件事变成一行命令：

$ python excel_extract.py project_tasks.xlsx

核心思路

脚本做的事只有三步，和第 11 课几乎一样，只是「读文件」那块换成了读 Excel：

  1. 读 Excel → 打开文件，读出每一行数据
  2. 组装成文字 → 把表格转成 AI 能看懂的自然语言描述
  3. 调 API 分析 → 让 AI 根据你的要求做汇总

新工具：openpyxl

openpyxl 是 Python 的一个库，专门用来读写 .xlsx 格式的 Excel 文件。

安装：

$ pip install openpyxl

最核心的三个概念：

概念代码类比
工作簿 load_workbook("文件名") 整本 Excel 文件
工作表 workbook.active（默认表）
workbook["Sheet1"]（按名字取）		 一个标签页
行/列 sheet.iter_rows(min_row=1, values_only=True) 逐行扫描数据

完整脚本

创建 excel_extract.py，复制以下代码：

from openai import OpenAI
from openpyxl import load_workbook
import sys

# 1. 配置
client = OpenAI(
    api_key="sk-你的密钥",      # ← 改成你的密钥
    base_url="https://api.deepseek.com"
)

# 2. 从命令行获取文件名
if len(sys.argv) < 2:
    print("用法: python excel_extract.py <Excel文件路径>")
    sys.exit(1)
file_path = sys.argv[1]

# 3. 读 Excel
wb = load_workbook(file_path)              # 打开工作簿
sheet = wb.active                           # 默认工作表

# 4. 把 Excel 数据组装成文字
rows_data = []
for row in sheet.iter_rows(min_row=1, values_only=True):
    # row 是一个元组，比如 ("需求文档编写", "张三", "2026-07-25", "进行中")
    # 过滤掉全空行
    if any(cell is not None for cell in row):
        rows_data.append(row)

# 5. 把行数据转成可读的文字
table_text = "以下是一个项目任务表格：\\n\\n"
for row in rows_data:
    # 把一行单元格用 | 分隔，拼成一行文字
    line = " | ".join(str(cell) if cell is not None else "" for cell in row)
    table_text += line + "\\n"

# 6. 调 API — 让 AI 分析表格
messages = [
    {
        "role": "system",
        "content": "你是一个项目助理，帮我分析项目任务表格。请输出：\\n\\n"
                     "## 整体概况\\n- 总任务数、已完成/进行中/未开始各多少\\n\\n"
                     "## 风险提示\\n- 已逾期或即将到期的任务（3天内截止还没完成）\\n\\n"
                     "## 负责人工作负载\\n- 每人手上有几个任务，状态如何\\n\\n"
                     "要求：简洁，不客套。\\n"
    },
    {
        "role": "user",
        "content": f"帮我分析这个项目任务表：\\n\\n{table_text}"
    }
]

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages
)

# 7. 输出结果
print("\\\\n" + "=" * 40)
print("📊 项目任务分析报告")
print("=" * 40)
print(response.choices[0].message.content)
print("=" * 40)

新知识点逐行拆解

代码新在哪儿？
from openpyxl import load_workbook 引入第三方库。openpyxl 不是 Python 自带的，需要 pip install openpyxl 安装。和之前 import sys（系统自带）不同
wb = load_workbook(file_path) 加载 Excel 文件。wb（workbook 的缩写）就是一个 Python 对象，代表整本 Excel
sheet = wb.active 获取默认工作表。一个 Excel 可能有多个 sheet，.active 取你最近打开的那个
for row in sheet.iter_rows(...) for 循环遍历每一行。——之前你见过 for 在小测里，这是第一次在实战里用。它会一行一行读取 Excel 的内容
values_only=True 只要值，不要格式。Excel 里的字体、颜色、公式等信息我们不需要，这个参数让 openpyxl 只返回单元格里的值
" | ".join(...) 拼接文字。把一行里的多个单元格值用 | 连接起来，变成一段可读的文字

为什么这个脚本特别实用

你只需要改 system prompt 里的模板，就能做完全不同的事：

换成这个 prompt结果
"找出所有状态不是已完成的任务，按截止日期排序" ❗ 逾期预警清单
"按负责人分组，列出每人手头的任务和状态" 👥 人员负荷表
"把表格转为 Markdown 格式" 📝 可直接粘贴到飞书/钉钉的表格
"把Excel内容转成日文" 🌏 跨语言汇报
💡 扩展思路：这个脚本绝不限于任务跟踪表。把你工作中任何 Excel 扔进去——报销单、会议记录、资源预算表、客户名单——改一行 system prompt 就能提取你要的内容。脚本本身只需要写一次。
📦 常用模板存档：建议把 excel_extract.py 复制几份，比如 risk_check.py、weekly_report.py，每份只改 system prompt。这样就有一组「Excel 小工具」了。

本课学了什么
