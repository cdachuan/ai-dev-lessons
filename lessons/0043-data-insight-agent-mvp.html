四、README 模板（面试官第一眼看的东西）

# 数据洞察 Agent

上传 CSV/Excel 数据，用自然语言提问，Agent 自主分析并生成图表报告。

## 功能
- 📂 支持上传 CSV/Excel 文件
- 💬 自然语言提问（如"各品类销售额排名"、"退款率最高的渠道"）
- 📊 自动生成交互式图表（柱状图、饼图、趋势图）
- ✅ 内置结果验证（空值检测、异常值告警、独立复算核验）
- 📝 每次分析生成完整过程记录（runs/*.json）

## 架构
ReAct 循环 + 5 个分析工具 + 结果验证卡口

## 快速开始
pip install -r requirements.txt
python main.py "各品类销售额（剔除退款）"

## 技术栈
Python · pandas · OpenAI API · pyecharts

五、评估集：3 个业务问题 + 预期答案

面试官会问：「你怎么知道你的 Agent 算的是对的？」答案就是评估集——一组固定问题 + 你手动算好的标准答案。

35 课你已经做过类似的（tests/eval.py）。现在把它扩展到业务问题级别：

#业务问题预期答案（口径）验证方式
Q1各品类销售额排名（剔除退款）数码 > 家居 > 服饰 > 食品group_sum + verify 独立复算
Q2哪个渠道的退款率最高？抖音退款率最高（已退款数/全部订单数）group_count 两次 + 手动除法
Q3一共有多少个不同客户？nunique() 的值（非 count）count_distinct + 独立 nunique 验证
⚠️ 评估集的核心：标准答案必须是你用独立代码手动算出来的，不能是 Agent 自己算的——否则就是「自己批改自己的卷子」。

六、动手任务：写出 3 个评估问题

  1. 挑 3 个业务问题——从电商场景出发，比如「各渠道销售额」、「退款率对比」、「客户数」。
  2. 用独立代码手动算出预期答案——不用 Agent 的工具，直接用 pandas 写一遍，把结果写死在 EXPECTED 字典里。
  3. 写测试函数——调用 Agent 工具，比对结果和 EXPECTED，打印 PASS/FAIL。
  4. 跑 selftest——python main.py --selftest，确认全部 PASS。
# tests/eval.py 里新增业务问题评估
EXPECTED = {
    "各品类销售额_剔除退款": {"数码": 15750, "家居": 6150, ...},
    "各渠道退款率": {"天猫": 3.4, "抖音": 17.6, ...},
    "不同客户数": 42,  # 用 nunique 算的
}
💡 评估集 = 简历加分项：面试官看到你有「固定测试问题集 + 自动化验证」，会立刻明白你不是只会调 API 的人——你懂工程质量。

🤔 小测

面试官问你：「你的 Agent 怎么保证算出的数据是对的？」以下哪个回答最能体现工程思维？

  1. 因为我用的是大模型，大模型算得准
  2. 我有固定测试问题集，每次发布前自动跑一遍验证
  3. 我让 Agent 自己检查自己的答案
  4. 我把代码发给别人帮我 review

（答案见底部）

💬 想拿你自己的数据试一下完整链路？把你的 CSV 文件放到 data/ 目录，改 tools.py 里的 DATA_FILE，然后问几个业务问题看看 Agent 的回答。任何不清楚的地方，都问你的 AI 教练。

小测答案：B。「有固定测试问题集，每次发布前自动跑一遍验证」——这是工程质量的体现：可重复、可自动化、有标准。A 错：大模型也会算错，「信任大模型」不是工程保证。C 错：Agent 自己检查自己等于没有检查——需要独立的验证。D 错：人工 review 不可重复、不可自动化，不如固定测试集可靠。
