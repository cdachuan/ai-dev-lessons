📝 搭一个模板自动填表脚本

第 0014 课 · 实践课 工具篇·四

🎯 增量胜利：学完这课，你就能写一个脚本——准备一份带空格的模板 + 一份数据，AI 自动把数据填进模板，产出规范文档。业绩责任书、收资表、周报套话，从此一键成稿。

场景：同一个模板，反复填不同数据

你手上有很多「格式固定、只换数据」的文档。比如一份业绩责任书模板：

兹聘任 {姓名} 担任 {部门} {职务}，本年度重点任务为 {任务}，考核目标为 {目标}。

每个人的信息不一样，但模板一模一样。手工填几十份既枯燥又容易填错。今天的脚本帮你自动填。

做法一：机械替换（占位符 → 数据）

最直接：模板里挖好 {姓名} 这样的坑，用 Python 的字符串替换填进去。连 AI 都不用调。

# 模板（挖好坑）
template = "兹聘任 {姓名} 担任 {部门} {职务}，本年度重点任务为 {任务}。"

# 数据
data = {"姓名": "张三", "部门": "计量中心",
        "职务": "主管", "任务": "完成智能计量平台验证"}

# 一行填充
result = template.format(**data)
print(result)
# → 兹聘任 张三 担任 计量中心 主管，本年度重点任务为 完成智能计量平台验证。
💡 什么时候用做法一：模板结构固定、数据字段明确、一一对应时。机械替换又快又准，还不花 API 钱。批量填几十份表首选这个。

做法二：AI 智能填充（数据不规整时）

但现实往往更乱：数据在一段自然语言里，字段对不上，还要润色。这时让 AI 来填——你给它模板 + 一堆原始信息，它自己判断哪块填哪。

from openai import OpenAI
client = OpenAI(api_key="sk-你的密钥", base_url="https://api.deepseek.com")

template = "兹聘任 {姓名} 担任 {部门} {职务}，本年度重点任务为 {任务}，考核目标为 {目标}。"

# 原始信息：一段乱糟糟的自然语言
raw_info = "李四，计量中心的技术骨干，今年提为技术专家岗。主要抓电能量预测赛道的数据集建设，年底要完成三大场景数据集，准确率目标定在95%以上。"

messages = [
    {"role": "system", "content":
        "你是文档助理。请把用户提供的原始信息，按给定模板填充完整，用词规范、书面化。只输出填好的文档，不要解释。"},
    {"role": "user", "content":
        f"模板：\n{template}\n\n原始信息：\n{raw_info}"}
]
resp = client.chat.completions.create(model="deepseek-chat", messages=messages)
print(resp.choices[0].message.content)
兹聘任 李四 担任 计量中心 技术专家岗，本年度重点任务为 牵头电能量预测赛道数据集建设、完成三大场景数据集制作，考核目标为 数据集准确率达到95%以上。

看到没——原始信息里没有明确的「职务=技术专家岗」「目标=95%」这种标签，AI 自己从大白话里抽取 + 归位 + 书面化，这是机械替换做不到的。

怎么选？

情况用哪种
数据规整、字段一一对应、量大做法一（.format()，免费又快）
数据是自然语言、要抽取、要润色做法二（AI 填充）
又想智能又想省钱先用 AI 抽成规整数据，再用做法一批量套

新知识点

代码说明
{姓名}模板里的占位符（挖好的坑）
template.format(**data)字典填充。** 把字典拆成 姓名="张三" 这样的参数，自动对号入座

本课学了什么

  • ✅ 用占位符 + .format() 做机械填充（免费、精准）
  • ✅ 用 AI 从自然语言里抽取信息、填进模板并润色
  • ✅ 判断什么场景用哪种：规整用机械、杂乱用 AI

🤔 小测

你要给 50 个人填格式完全一样的工牌信息，数据已经整理成规整的表格。用哪种做法最合适？

  1. 做法二 AI 填充，每人调一次 API
  2. 做法一 .format() 机械替换，循环 50 次，一分钱不花
  3. 手工一个个填
  4. 两种都不行
