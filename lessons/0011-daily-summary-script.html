场景：每天都要写的日报

作为项目助理，你可能每天要处理这样的文字：

今天完成了会议纪要整理，与供应商沟通了发货时间，确认了 A 项目的第三季度预算。下午参加了产品评审会，讨论了新功能的优先级。明天需要跟进合同签署。

以前的做法：打开赫默 → 粘贴文字 → 说"帮我总结成日报格式" → 复制出来 → 调整格式。每天重复。

今天的脚本，把这件事变成一行命令：

$ python daily_summary.py daily_note.txt

和之前的脚本有什么不同？

第 5 课你已经写过「读文件 → 调 API → 输出」的脚本。今天升级三点：

对比项第 5 课今天（第 11 课）
文件路径 写死在代码里 命令行参数 —— 每次可以指定不同文件
输出格式 自由文本 结构化输出 —— 按照固定格式（待办/进展/问题）
用途 一次性运行 每天重复用 —— 不改代码，只改文件名

完整脚本

创建 daily_summary.py，复制以下代码：

from openai import OpenAI
import sys

# 1. 配置
client = OpenAI(
    api_key="sk-你的密钥",      # ← 改成你的密钥
    base_url="https://api.deepseek.com"
)

# 2. 从命令行获取文件名
if len(sys.argv) < 2:
    print("用法: python daily_summary.py <文件路径>")
    sys.exit(1)
file_path = sys.argv[1]

# 3. 读文件
with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()

# 4. 构造消息 — 这次用了 system prompt
messages = [
    {
        "role": "system",
        "content": """你是一个项目助理，帮我把日常工作记录整理成结构化的日报。
按以下格式输出：

## 今日完成
- （列出完成事项）

## 明日计划
- （列出计划事项）

## 待跟进
- （需要持续跟踪的事项，如有）

要求：简洁，每条一句话，不要说客套话。"""
    },
    {
        "role": "user",
        "content": f"帮我整理以下工作记录：\n\n{content}"
    }
]

# 5. 调 API
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages
)

# 6. 输出
print("\\n" + "=" * 40)
print("📋 日报摘要")
print("=" * 40)
print(response.choices[0].message.content)
print("=" * 40)

新知识点逐行拆解

代码新在哪儿？
import sys 引入 Python 系统库。sys.argv 能拿到运行脚本时在命令行输入的参数，比如 python daily_summary.py report.txt 中的 report.txt
sys.argv[1] 取命令行参数。sys.argv[0] 是脚本名本身，sys.argv[1] 是第一个参数（文件名）
if len(sys.argv) < 2: 参数校验——如果用户忘记传文件名，告诉对方怎么用，而不是报个看不懂的错误
"role": "system" System Prompt 的应用。第 7 课的概念今天变成真实代码——设定一个固定角色，每次运行都生效
messages = [ ... ] 多条消息。之前只用了 1 条 user 消息，现在是 system + user 两条，模型会先理解角色再执行任务

试试运行

  1. 在当前目录下创建 daily_note.txt，写一段你今天的工作记录（随便几句话就行）
  2. 把脚本里的 api_key 改成你的 DeepSeek API Key

一劳永逸的小技巧

脚本写好后，以后每天只需：

  1. 用记事本写下今天的工作流水账，存成 daily_note.txt
  2. 运行 python daily_summary.py daily_note.txt
  3. 直接复制输出到日报里

整个过程不到 10 秒。比起手动打开赫默、粘贴、等回复、复制、调整格式——省了 90% 的时间。

💡 扩展思路：不改代码，改 system prompt 里的模板，就能变成周报、会议纪要、事项清单提取。甚至可以改成两种语言对照输出（英文日报）。这个脚本的核心价值在于——模板化 + 复用。
