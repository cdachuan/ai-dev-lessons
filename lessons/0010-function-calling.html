那如果我们给 AI 一双手呢？

什么是 Function Calling？

💡 一句话

Function Calling = 让 AI 模型能请求调用你预先写好的函数（工具）。
模型自身不执行代码，它只是决定「该用什么工具、传什么参数」，由你的程序去执行。

流程是这样的：

你提问 → AI 判断需要工具 → 返回工具名+参数
↓
你的代码实际执行工具 → 拿到结果
↓
把结果塞回给 AI → AI 组织语言回答你

举个具体例子——你问「北京今天多少度？」：

步骤做了什么谁做的
1. 解析意图 用户想查天气 → 需要「查询天气」工具 AI 模型
2. 调用工具 调用 get_weather(city="北京") 你的代码（不是 AI！）
3. 返回结果 「北京当前温度 32°C，晴」 天气 API
4. 组织回答 「北京今天 32°C，挺热的，建议带伞防晒」 AI 模型

一个完整的例子：骰子工具

我们写一个最简单的工具——掷骰子。AI 不会凭空产生随机数，但它可以调用你的 roll_dice 函数。

from openai import OpenAI

client = OpenAI(api_key="sk-你的密钥", base_url="https://api.deepseek.com")

# —— 1. 定义工具 ——
tools = [
    {
        "type": "function",
        "function": {
            "name": "roll_dice",
            "description": "掷一个 N 面骰子，返回 1~N 之间的随机数",
            "parameters": {
                "type": "object",
                "properties": {
                    "sides": {
                        "type": "integer",
                        "description": "骰子的面数，默认 6",
                    }
                },
                "required": []
            }
        }
    }
]

# —— 2. 发消息（带工具定义） ——
messages = [{"role": "user", "content": "帮我掷一个 20 面骰子"}]
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages,
    tools=tools      # ← 关键：告诉 AI 有这些工具可用
)

# —— 3. AI 决定调用工具 ——
msg = response.choices[0].message
print(f"AI 想调用的工具：{msg.tool_calls[0].function.name}")
print(f"参数：{msg.tool_calls[0].function.arguments}")

# —— 4. 实际执行工具 ——
import json, random
args = json.loads(msg.tool_calls[0].function.arguments)
result = random.randint(1, args.get("sides", 6))
print(f"掷骰结果：{result}")

# —— 5. 把结果送回给 AI 组织回答 ——
messages.append(msg)
messages.append({
    "role": "tool",
    "tool_call_id": msg.tool_calls[0].id,
    "content": str(result)
})
final = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages
)
print(f"AI 最终回答：{final.choices[0].message.content}")

逐行解释

代码什么意思
tools = [...] 给 AI 一份工具清单，告诉它「你有这些工具可以用」
每个工具必须声明：名字、描述（AI 靠描述判断何时用）、参数（什么参数、什么类型）
tools=tools API 调用时把工具清单传进去，AI 就知道「这次对话我可以调用工具」
msg.tool_calls AI 的回复里如果有 tool_calls，说明它想调用工具。它不会自己执行，只返回「我想调用 roll_dice，参数为 {"sides": 20}」
role: "tool" 你把工具执行结果送回对话时的固定角色。告诉 AI：「这是刚才那个工具调用的结果，基于此回答用户」
第 2 次 API 调用 第一次调用让 AI 决定了用什么工具。第二次调用把工具结果喂回去，让 AI 组织成自然语言
⚡ 关键理解：AI 模型不执行代码。它只做两件事：
① 判断「用户这个问题需要调用哪个工具」
② 提取出正确的参数
实际执行代码的是你——你的 Python 脚本拿到参数后真正去跑函数。

和赫默 agent 的关系

🔗 你现在就在用 Function Calling

你现在跟我聊天时，我回答里出现的「查文件」「搜网页」「读数据库」——全都是 Function Calling。你看到我写 web_search()、read_file() 这些工具调用，本质上就和上面骰子的例子一模一样：

  • 你的问题 → 我（AI）判断需要什么工具
  • Hermes 框架执行工具 → 返回结果
  • 我基于结果组织回答

现在你从「使用者」变成「创造者」了——你也可以写自己的工具！

可以写什么工具？

工具可以是任何 Python 函数：

工具功能对你有什么用
search_file(keyword) 在指定文件夹里搜索文件 不用记住文件放哪了
read_excel(path) 读取 Excel 表格的关键数据 让 AI 帮你分析报表
send_wechat(msg) 通过接口发微信消息 AI 帮你通知人
summarize_doc(path) 读文档返回摘要 第 5 课的升级版
query_db(sql) 查数据库 让 AI 直接给你数据

你只需要定义好「名字、描述、参数」三样东西，AI 就能自动学会什么时候调用哪个工具。
