## 3. 带 key 的完整 Agent 效果

配 `DEEPSEEK_API_KEY` 后 `python main.py "各品类销售额是多少（剔除退款）？"`，
Agent 会: 选 profile → group_sum → 用 verify 独立复算 → 输出带口径说明的结论，
完整过程落盘在 `runs/` 目录（工具、参数、中间结果、最终答案全程留痕）。

## 4. 面试可讲的设计点

- **verify 独立复算**: 结论给出前用另一条计算路径核对，防模型算错数（呼应"永远别信任模型原生输出"）
- **runs/ 全程留痕**: 每次提问可审计，出问题能回放
- **离线自测先行**: 不花一分钱 key 也能验证数据口径一致
