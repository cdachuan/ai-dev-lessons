# data_doctor · 数据体检器（可复用工具）

> 任意 CSV 一键诊断：画像 + 质量问题 + 清洗建议 + 健康分。
> 设计原则（41课三护栏）：**检测 → 建议 → 留痕**。工具只诊断，**不自动改数据**——清洗是业务决策，不是代码决策。

## 用法

```bash
# 一键全检
python cli.py <csv路径>

# 单列异常检测（50课口径：偏态用iqr，近正态用zscore）
python cli.py <csv路径> --outliers UnitPrice --method iqr
```

```python
from doctor import profile, quality_report, outliers, suggest_clean, full_check
r = full_check("data.csv")   # 结构化返回 {"ok":bool, "data":{...}}，可接Agent
```

## 实跑记录（2026-09-20，54万行真实电商数据）

```
==================================================
数据体检报告
==================================================

[画像] 541,909 行 × 8 列, 205.4 MB

[质量问题]
  - 完全重复行 5268 行

[清洗建议]
  - `CustomerID` 数值列有缺失 → 先查缺失机制（随机?系统性?），再定填中位/均值/标记
  - `UnitPrice` 含非正值 → 查业务含义（退货/赠品/错误），不能默默删
  - 重复行 5268 → 查是否真重复（同key不同批次?），再决定去重

[健康分] 90/100
```

**验收细节**：抓到的 5268 重复行与 UCI 官方数据集文档声明完全一致 ✓
（这说明重复是该数据集的已知特性，不是 bug——工具抓到后仍要人工判断「去重还是保留」，这正是建议里写「查是否真重复」的原因。）

## 设计要点（面试可讲）

- **诊断与治疗分离**：只建议不动手，清洗决策留给懂业务的人
- **偏态感知**：默认 IQR（50课：金额类天然右偏，3σ会漏大额异常）
- **大文件友好**：>100MB 自动分块读取
- **结构化返回**：`{"ok","data","error"}` 统一格式，可直接注册进 insight_agent_mvp 当工具
