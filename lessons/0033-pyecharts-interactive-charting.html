第 33 课 · pyecharts：交互式图表升级

P5 实战篇类型：实践课预计 25 分钟

一句话心法：matplotlib 负责「画出来」，pyecharts 负责「让人看懂」——交互不是炫技，是把「放大看细节」的权利交给看图的人。而它落盘成 HTML 文件的形态，恰好就是上一个探讨里「黑板可观察」的天然载体。

一、为什么升级：matplotlib 的三个天花板

场景matplotlibpyecharts
给领导演示某品类占比静态图片，细节靠嘴说鼠标悬停显示具体数值，图自己会说话
数据点太多全挤在一起dataZoom 拖拽缩放，先看趋势再看局部
想隐藏某些系列对比改代码重画图例点一下就切换

判断标准很简单：给自己看 → matplotlib 够用；给别人看（汇报/黑板展示）→ pyecharts。

二、最小可用代码（已实跑验证）

演示数据：60 行电商订单 orders_60.csv（与 31 课 orders.csv 同结构，在 D:\学习\AI\工具实操\）。

import pandas as pd
from pyecharts.charts import Bar
from pyecharts import options as opts

df = pd.read_csv(r"D:\学习\AI\工具实操\orders_60.csv")

# 口径先行（31课心法）：算销售额，先剔除退款单
done = df[df["status"] == "已完成"]
sales = done.groupby("category")["amount"].sum().sort_values(ascending=False)

bar = (
    Bar()
    .add_xaxis(sales.index.tolist())          # X轴：品类
    .add_yaxis("销售额(元)", sales.values.tolist())
    .set_global_opts(title_opts=opts.TitleOpts(title="各品类销售额（剔除退款）"))
)
bar.render("品类销售额.html")   # ← 输出是一个HTML文件，浏览器打开即交互
注意两个习惯：① 链式写法 ( Bar().add_xaxis()... ) 是 pyecharts 惯例，从上往下读就是配置顺序；② render() 产出的是独立 HTML 文件——双击就能发给别人看，不需要装 Python。

三、常用三招（够覆盖 90% 汇报场景）

# 1. 悬停提示（默认就有，可自定义单位）
.set_series_opts(tooltip_opts=opts.TooltipOpts(formatter="{b}: {c} 元"))

# 2. 区域缩放——数据点多的图必加
.set_global_opts(datazoom_opts=[opts.DataZoomOpts()])

# 3. 换图型只是换一个类
from pyecharts.charts import Pie, Line, Bar
pie = (
    Pie()
    .add("销售额", [list(z) for z in zip(sales.index, sales.values)])
    .set_global_opts(title_opts=opts.TitleOpts(title="品类占比"))
)

记住映射关系：X轴数据 → add_xaxis，系列数据 → add_yaxis/add，全局配置（标题/缩放）→ set_global_opts，系列配置（提示/标签）→ set_series_opts。四个方法名就是全部骨架。

四、和黑板的衔接（探讨成果落地）

上一个探讨里说黑板要「可观察」——pyecharts 的 render 产物就是最便宜的实现：每个 step 跑完顺手 render 一张图，黑板里挂上文件路径。看黑板的人点开就是可交互的图，不用读代码。这条路径在 34 课搭 Agent 时会正式接进去。
