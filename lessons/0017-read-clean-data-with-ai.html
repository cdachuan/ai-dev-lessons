🔌 用 AI 写代码：读取和清洗业务数据

第 0017-0018 课 · 应用篇·一 实践课

🚀 Phase 3 开始！Phase 2 你搭了5个工具，骨架都是「读入 → 组装 → 调用」。Phase 3 更进一步：让 AI 直接帮你写数据分析代码，你负责指挥和验收。

核心技能：AI 辅助编程四步循环

你已经会 pandas 基础（groupby、筛选、merge 都能秒答）。现在学一个更高效的用法：让 AI 帮你写代码，你负责审查和验收。

步骤你做什么AI 做什么
① 描述说清数据格式 + 目标—
② 生成—产出 pandas 代码
③ 验证跑代码，检查输出—
④ 迭代指出问题修改代码

这个循环会贯穿 Phase 3 所有课程。你不需要记住每个 pandas 函数，但必须学会怎么描述需求、怎么验收结果。

第一步：读取业务数据

假设你拿到一份电表日抄数据 CSV，列长这样：

台区编号, 电表号, 抄表日期, 读数(kWh), 电压(V), 电流(A)
T001, M10023, 2026-07-01, 15320.5, 220.1, 5.2
T001, M10023, 2026-07-02, , 219.8, 5.1    # ← 读数缺失
T002, M10045, 2026-07-01, 8920.0, 221.0, 3.8

你跟 AI 说：

"我有一个 CSV 文件，列是：台区编号、电表号、抄表日期、读数(kWh)、电压(V)、电流(A)。帮我写 pandas 代码读进来，看看数据基本情况。"

AI 会生成类似代码：

# 读取
df = pd.read_csv("电表数据.csv", encoding="utf-8")

# 三板斧检查
print(df.head())      # 看前5行长什么样
print(df.info())      # 看列名、类型、缺失情况
print(df.shape)       # 看多少行多少列

怎么让 AI 写出好代码

关键在给足上下文。三样东西必须给：

  1. 数据格式：CSV 还是 Excel？编码是 utf-8 还是 gbk？
  2. 样本数据：贴 2-3 行真实数据给 AI 看（让它知道列名和格式）
  3. 你的目标：读出来看看？算汇总？筛选异常？
💡 常见坑：如果你只说"帮我读 CSV"，AI 不知道你的编码格式（中文 Windows 默认 gbk），不知道列名，生成的代码可能跑不通。多说两句，省十次调试。

第二步：清洗脏数据

真实数据总有毛病。告诉 AI 具体问题，让它写清洗代码：

问题你怎么描述AI 会用的方法
有缺失值"读数列有空值"df.dropna() 删掉 / df.fillna(0) 填充
日期是字符串"抄表日期是文本不是日期"pd.to_datetime(df['抄表日期'])
有重复行"可能有重复抄表记录"df.drop_duplicates()
数字是文本"读数被读成了字符串"df['读数'].astype(float)

你不需要记住这些函数名——你只需要能用大白话描述问题，AI 就知道该用哪个。

最关键的一步：验收

AI 写的代码不能盲信。每段代码跑完后，检查三件事：

验收三问：
  1. 数据量对吗？ — df.shape 行数和预期差不多？
  2. 数据值对吗？ — df.head() 数值合不合理？
  3. 类型对吗？ — df.info() 日期是 datetime、数字是 float？

不确定某行代码什么意思？直接问 AI："第3行代码是什么意思？为什么要这么写？" 如果 AI 解释不清，那行代码可能有问题。

完整示例：从脏数据到干净数据

# 你跟 AI 说：
# "我有一份电表抄表数据 CSV，编码可能是 gbk。
#  列：台区编号、电表号、抄表日期、读数、电压、电流。
#  问题：读数有空值，日期是文本，可能有重复行。
#  帮我读取并清洗，输出清洗前后的行数对比。"

# AI 生成的代码：
df = pd.read_csv("电表数据.csv", encoding="gbk")
print(f"原始数据：{df.shape[0]} 行")

df = df.drop_duplicates()                            # 去重
df['抄表日期'] = pd.to_datetime(df['抄表日期'])         # 日期转类型
df['读数'] = pd.to_numeric(df['读数'], errors='coerce') # 数字转类型
df = df.dropna(subset=['读数'])                       # 删掉读数为空的行

print(f"清洗后：{df.shape[0]} 行")
print(df.head())

Phase 3 的核心转变

Phase 2 你亲手写代码，Phase 3 你指挥 AI 写代码。你的角色从「码农」变成「技术评审」：

  • 你不需要记住 pd.to_numeric() 怎么拼
  • 但你需要知道清洗后该检查什么
  • 你需要能看懂 AI 写的代码，判断对不对
  • 你需要能用精准的语言描述问题，让 AI 一次写对

🤔 小测

你让 AI 写了一段读取 CSV 的代码，运行后第一步该做什么？

  1. 直接信任，继续往下写
  2. 跑 .head() 和 .info() 检查数据读对没有
  3. 把代码背下来
  4. 关掉电脑回家
