🎲 A/B 测试全流程：设计 / 样本量 / 避坑

第 0052 课 · 选修线二 统计与实验 · 预计 25 分钟

🎯 本课目标：掌握 A/B 测试的完整生命周期和四个经典坑——其中「偷看结果」这个坑，用模拟实验亲手复现：假阳性率从 5% 飙到 38%。

一、A/B 测试是什么：受控实验的电商化

把用户随机分成两组：A 组看旧版页面，B 组看新版。跑一段时间，比转化率。「随机」是灵魂：它让两组在所有维度（新老客/渠道/设备）上分布均衡，剩下的差异只能来自改动本身——这是观察性数据永远给不了的能力（53 课因果课展开）。

二、先算样本量：不够就别开跑

「测一周看看」是外行话。样本量由四个参数决定，开跑前算清楚：

参数含义本例取值
基线转化率 p₁现在版本的水平10%
最小可检测提升小到没意义的提升不想测→ 10.5%（相对+5%）
显著性 α假阳性容忍度（没效果却报有效）0.05
功效 power真有效时能测出来的概率0.8
 
from statistics import NormalDist
z_a = NormalDist().inv_cdf(1 - alpha/2)     # 1.96
z_b = NormalDist().inv_cdf(power)           # 0.84
n = ceil((z_a*sqrt(2*pbar*(1-pbar)) + z_b*sqrt(p1*(1-p1)+p2*(1-p2)))**2 / (p2-p1)**2)

实算结果：每组 57,763 个样本（10%→10.5% 这么小的提升，代价就是近 6 万样本/组）。若你的页面日 UV 5000，要跑 23 天——开跑前就该知道，而不是跑三天看「没效果」就下结论。

三、跑起来：流程与检查

  1. 定指标：主指标 1 个（转化率），护栏指标若干（客单价不许跌、退货率不许涨）
  2. 随机分流：按用户 ID 哈希分流（同一人始终同组），不是按请求随机
  3. 跑满预定期：样本量算出 23 天就跑 23 天，中途不看、不加单、不提前开香槟
  4. 检验+效果量：p 值（真假）+ 效果量（大小）+ 分段检查（新老客是否一致，防辛普森）

四、四大坑（模拟复现第一个）

坑1 · 偷看结果（peeking）—— 用模拟亲手复现

构造一个真实无差异的实验（两组真实转化率都是 10%），跑 300 次：

做法假阳性率
按规矩跑完一次检验（α=0.05）4.7% ≈ 理论值 5%
每积累一段就偷看，任一次显著就宣布赢（10 个检查点）38%
⚠️ 这就是「跑了三天看显著就停」的真相：你把 5% 的假阳性率偷换成了近 40%。止血法：固定样本量跑满再验一次；要中途看就用序贯检验（alpha spending）方案，别裸看。

坑2 · 辛普森悖论

整体显著≠分组一致。必须按新老客/渠道分段复核，方向不一致比不显著更危险（构造案例见 53 课）。

坑3 · 多重比较

同时测 20 个新版本，总有「碰巧显著」的：20 个检验全对的概率只有 0.95²⁰≈36%。对策：只测一个主假设，或用 Bonferroni 校正（α 除以检验次数）。

坑4 · 新奇效应

新版本头几天点击率高，因为「新鲜」，之后回落。对策：跑满整数周期（整周），或对比首周与末周的表现。

动手任务（30 分钟）

  1. 跑通样本量计算：把期望提升改成 +20%（10%→12%），看样本量掉到多少——体会「检测越小差异越贵」。
  2. 复现偷看模拟：无差异实验 + 10 个检查点，对上 ~38% 假阳性。
  3. 把检查点减到 3 个，看假阳性率怎么变。
  4. 设计一个你司场景的 A/B：主指标、护栏指标、样本量、跑几天，写成一页纸。
🎯 本课核心结论：A/B 测试 90% 的错误发生在开跑之前：没算样本量、没定主指标、没防偷看。跑起来之后反而简单——「随机分流 + 跑满周期 + 一次检验 + 分段复核」。

本课学了什么

  • ✅ 样本量四参数：基线/最小提升/α/power，10%→10.5% 要 57763/组
  • ✅ 偷看灾难：10 个检查点把假阳性 5%→38%（模拟实测）
  • ✅ 主指标+护栏指标：防「转化涨了退货也涨」
  • ✅ 按用户哈希分流：不是按请求随机
  • ✅ 多重比较/新奇效应：一次一个假设，跑满整周期

🤔 小测

实验跑到第 5 天（预定期 23 天），数据已经 p=0.03 了。正确做法？

  1. 显著了，立刻全量上线，省 18 天
  2. 继续跑满 23 天，跑完做一次正式检验（或采用预设的序贯方案）
  3. 把 p=0.03 报给老板，让他决定
  4. 提前关实验，但多验几组指标找支撑

小测答案：B。样本量就是检验的「契约」——中途停 = 偷看 = 假阳性率 5%→38%（本课实测）。
A 错：正是偷看行为，这个 p=0.03 有近四成概率是运气。
C 错：把统计决策甩给不了解偷看风险的人，等于把错误合法化；正确做法是解释「为什么要跑满」。
D 错：挑指标找支撑 = p-hacking，比偷看更糟。实验的可信度建立在「规则先于数据」上。
