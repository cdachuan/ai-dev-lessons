🧪 假设检验与置信区间（电商场景）

第 0051 课 · 选修线二 统计与实验 · 预计 25 分钟

🎯 本课目标：用置换检验和bootstrap这两个「靠洗牌和抽样就能懂」的方法建立检验直觉——不推公式，代码 10 行。跑的是你的真实数据：荷兰客单 £2,847 vs 德国 £368，这差异是真的大还是运气？

一、检验在回答什么问题

你观察到差异（£2,479）。但任何两组数据几乎都会有差异——问题永远是：「如果两国客单其实一样，纯靠抽样的运气，能不能凑出这么大差异？」

  • 能轻易凑出来 → 差异不稀奇 → 别下结论
  • 凑不出来（概率极小）→ 差异是真的 → 可以报告

p 值 = 「纯运气凑出这么大差异」的概率。p 很小（惯例 < 0.05）→ 运气解释不通 → 我们说「统计显著」。

二、置换检验：洗牌 2000 次的暴力美学

思路朴素到不像统计：把两国所有订单混在一起洗牌，随机重新分成两组，算一次「组均值差」；重复 2000 次，看看「纯洗牌能产生多大差异」的分布：

import random
random.seed(42)
pooled = list(nl) + list(de)        # 荷兰100单 + 德国603单的金额
n = len(nl)
diffs = []
for _ in range(2000):
    s = random.sample(pooled, len(pooled))   # 洗牌
    diffs.append(sum(s[:n])/n - sum(s[n:])/len(s[n:]))  # 重算组间差

obs = nl.mean() - de.mean()          # 真实观察差 = 2479
extreme = sum(1 for d in diffs if abs(d) >= abs(obs)) / len(diffs)
# → p ≈ 0.0000（2000次洗牌没有一次凑出这么大差异）

真实结果：观察差 £2,479，2000 次洗牌一次都没接近过 → p≈0.0000 → 荷兰客单显著高于德国。注意 p 不会真是 0，只能说「< 1/2000」，想更精确就多洗几轮。

📌 置换检验的好处：不假设分布形状（50 课说过金额右偏，t 检验的假设勉强）、逻辑透明可讲给业务听（「洗牌 2000 次都凑不出」）、代码 10 行。面试讲这个比背 t 检验公式加分。

三、置信区间：「均值 ± 多大误差」的诚实版

「荷兰客单 £2,847」是 100 单算出来的点估计。换 100 单可能就是 £2,600。bootstrap：从这 100 单里有放回抽样 100 单算均值，重复 3000 次，看均值的波动范围：

for _ in range(3000):
    s = [random.choice(inv) for _ in inv]   # 有放回抽样
    means.append(sum(s)/len(s))
# 95% CI ≈ [P2.5, P97.5] = [2044, 3762]

真实结果：荷兰客单 £2,847，95% 置信区间 [£2,044, £3,762]。含义：「如果重复取样，95% 的样本会算出这个区间内的均值」——区间这么宽是因为只有 100 单。报数时带上区间，比光秃一个点诚实十倍。

四、三个必答的坑

坑说明
p<0.05 ≠ 差异大样本够大时极小差异也显著。p 管真假，效果量管大小，两个都要报
不显著 ≠ 没差异可能只是样本不够（荷兰才 100 单，CI 宽成 £1700 就是证据）
多重比较38 个国家两两比一遍，总有「碰巧显著」的——检验次数越多，假阳性越多（下节课细讲）

动手任务（25 分钟）

  1. 跑通置换检验，对上 p≈0.0000；把洗牌次数改成 200 次再看 p 的稳定性。
  2. 把荷兰样本随机抽 30 单重跑 bootstrap，观察 CI 变宽多少——体会样本量的代价。
  3. 挑两个相邻国家（如法国 vs 德国）做置换检验，找一个「不显著」的例子并解释。
🎯 本课核心结论：假设检验回答「差异能不能用运气解释」：置换检验=洗牌造出「运气分布」，bootstrap=重抽样造出「均值波动范围」。报结论时三件套：点估计 + 区间 + p 值，缺一个都不完整。

本课学了什么

  • ✅ p 值直觉：纯运气凑出现察差异的概率
  • ✅ 置换检验：洗牌 2000 次，暴力但不依赖分布假设
  • ✅ bootstrap CI：荷兰客单 [2044, 3762]，区间宽度暴露样本量
  • ✅ 显著≠大，不显著≠无：p 值和效果量是两回事

🤔 小测

某次实验 p=0.04，另一个实验 p=0.20 但样本量大 10 倍。哪个说法对？

  1. p=0.04 的实验效果一定更大
  2. p=0.20 的实验可能效果一样大，只是样本还不够；p=0.04 的效果也可能很小
  3. p=0.20 说明两个版本完全一样
  4. 直接看 p 值大小排序效果即可
