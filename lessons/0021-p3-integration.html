🎯 本课目标：把前三课学的「算 → 判 → 画」三步组装成一个完整可运行的 Python 脚本。学完这课，你能用一个脚本自动生成台区用电月度分析报告。

回顾：三步走骨架

前三课你分别学了三块技能：

步骤做什么用什么产出
① 算从原始数据算出指标pandas groupby + agg一张结果表
② 判把数字喂给 AI，让它下结论DeepSeek API一段结论文字
③ 画把数字变成直观的图matplotlib一张图片文件

之前三课每课只练一步，今天把三步串成一条流水线。这就是 Phase 3 的收尾任务。

核心认知：数据在步骤间流转

🔑 关键认知：整合不是把三段代码拼在一起，而是让数据在步骤之间流转。前一步的输出，是后一步的输入。

流水线的数据流向：

原始数据(df)
    │
    ▼ pandas groupby + agg
结果表(result)
    │
    ├──► 数字 → AI 推理 → 结论文字
    │
    └──► 数字 → matplotlib → 图片文件

注意：result 这张中间表是枢纽。它既被 AI 拿去下结论，又被 matplotlib 拿去画图。不是各算各的，而是从同一份结果出发。

脚本结构：三个区块

一个完整的数据分析脚本，结构永远是这三块：

import matplotlib.pyplot as plt
from openai import OpenAI

# ━━━ ② 函数定义：核心逻辑包成一个函数 ━━━
def analyze_and_report(df):
    # 算 → 判 → 画 全在这里
    ...

# ━━━ ③ 主程序：读数据、调函数、出结果 ━━━
df = pd.read_csv('台区用电.csv')
analyze_and_report(df)

为什么要包成一个函数 analyze_and_report(df)？因为这样输入变了，逻辑不用改。今天分析台区用电，明天换个 CSV 分析别的，函数内部的算→判→画流程是通用的。

完整示例：台区用电月度分析报告生成器

下面是一个完整可跑的脚本，大约 45 行。它从 CSV 读取台区用电数据，算出每个台区的月度用电波动，让 AI 下结论，画出柱状图，最后把结论存成文本文件、图存成图片文件——一份报告就出来了。

# pip install pandas matplotlib openai
import pandas as pd
import matplotlib.pyplot as plt
from openai import OpenAI

client = OpenAI(api_key="你的API密钥", base_url="https://api.deepseek.com")

plt.rcParams['font.sans-serif'] = ['SimHei']
plt.rcParams['axes.unicode_minus'] = False

def analyze_and_report(df):
    # ① 算：每个台区的月度用电波动幅度（最大-最小）
    result = df.groupby('台区编号')['用电量'].agg(['max', 'min'])
    result['波动幅度'] = result['max'] - result['min']
    result = result.sort_values('波动幅度', ascending=False)

    # ② 判：把数字喂给 AI，让它下结论
    data_str = result[['波动幅度']].head(10).to_string()
    prompt = f"""以下是台区月度用电波动数据（单位kWh）：
{data_str}

请分析：哪个台区波动最异常？整体波动水平如何？给出简短结论（3-5句话）。"""
    resp = client.chat.completions.create(
        model="deepseek-chat",
        messages=[{"role": "user", "content": prompt}]
    )
    conclusion = resp.choices[0].message.content

    # ③ 画：波动 Top 10 柱状图
    top10 = result.head(10)
    plt.figure(figsize=(10, 5))
    plt.bar(top10.index, top10['波动幅度'])
    plt.title('台区用电波动幅度 Top 10')
    plt.xlabel('台区编号')
    plt.ylabel('波动幅度 (kWh)')
    plt.xticks(rotation=45)
    plt.tight_layout()
    plt.savefig('台区波动图.png', dpi=150)

    # 输出报告
    with open('分析报告.txt', 'w', encoding='utf-8') as f:
        f.write('=== 台区用电月度分析报告 ===\n\n')
        f.write(conclusion)

    return conclusion

# ━━━ 主程序 ━━━
df = pd.read_csv('台区用电.csv')
report = analyze_and_report(df)
print(report)
print('\n报告已保存：分析报告.txt + 台区波动图.png')
💡 数据流向：CSV → df → groupby 算出 result → result 同时喂给 AI（出文字）和 matplotlib（出图）→ 两份文件落地。一张表驱动两个产出，这就是流水线。

让 AI 帮你写这种长脚本

这种 40-50 行的脚本，手写容易漏东西。更好的办法是给 AI 完整上下文，让它一次生成：

"我有一个 CSV 文件，列是：台区编号、日期、用电量。帮我写一个 Python 脚本，完成以下任务：
1. 用 pandas groupby 算每个台区的用电波动幅度（max-min）
2. 把 Top 10 的波动数字喂给 DeepSeek API，让它下结论
3. 用 matplotlib 画 Top 10 波动柱状图，存成 PNG
4. 结论存成 txt 文件
输出格式：一个完整可跑的脚本，中文注释"
📝 给 AI 的上下文清单：① 数据格式（列名、单位）② 三步需求（算什么、判什么、画什么）③ 输出格式（存什么文件）④ 语言要求（中文注释）。四样给全，AI 一次就能生成可跑的脚本。

验收要点：三个检查

脚本跑完了不等于对了。养成三看的习惯：

检查项看什么怎么看
① 数字对不对pandas 算出的波动值和原始数据是否吻合抽 1-2 个台区，手动验算 max-min
② 结论通不通AI 说的数字和 pandas 算出的数字是否一致对照 result 表，看 AI 有没有编数字
③ 图能不能看柱状图有没有中文乱码、标签是否清晰打开 PNG 文件肉眼看
⚠️ AI 会编数字：AI 下结论时偶尔会"编"一个看似合理但不准确的数字（比如把 600 说成 800）。结论里的每一个数字，都应该能在 result 表里找到对应。找不到就是 AI 编的，不能写进报告。

这就是你的第一个 AI 数据分析工具

到这一步，你已经拥有了一个可重复使用的自动化分析工具：

  • 换一份 CSV，改个文件名就能跑
  • 换一个分析维度，改 groupby 的列名就行
  • 换一个画图类型，改 plt.bar() 为 plt.plot() 就行

这就是「算 → 判 → 画」三步走的力量——骨架不变，内容可换。以后工作中遇到任何数据分析需求，先想：哪步算、哪步判、哪步画，然后让 AI 帮你填代码。

🤔 小测

你的分析脚本跑完了，数字和图都出来了，但 AI 下的结论里说「台区 T07 波动幅度为 600kWh，超过平均值 2 倍」，你怎么验证这个结论靠不靠谱？

  1. 直接信 AI，它能推出结论说明没问题
  2. 回头检查 pandas 算出的原始数字，确认 600 和平均值确实差 2 倍
  3. 重新让 AI 算一遍，看两次结果一不一样
  4. 换一个 AI 模型再问一遍
