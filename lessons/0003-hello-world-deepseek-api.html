📚 第 3 课 · Hello World — 用 Python 调一次 DeepSeek API

2026-07-01 · 阅读约 5 分钟 · 术语表

一句话讲清

用不到 10 行 Python 代码，让 DeepSeek 的 AI 模型直接回答你的问题——不再通过赫默，而是你亲手写的程序调用 API。

🎯 今天学完你能做这件事：
在自己的电脑上写一个 Python 脚本，运行后输入任何问题，AI 直接给出回答。这是你搭建 AI 小工具的第一步。

你需要准备什么？

在开始之前，先确认三样东西：

你需要说明有了吗？
Python 环境 你的电脑上能运行 Python 3.8+ 赫默终端里 python --version 可查
DeepSeek API Key 调用 API 的「密码」，去 platform.deepseek.com 免费注册获取 需要注册，首次送 500 万 token
openai 库 Python 里调 DeepSeek API 的工具包 pip install openai 安装
⚠️ 重要提醒：API Key 就是你的密码。永远不要把它写在代码里给别人看，不要上传到 GitHub。后面课程会教你怎么安全地管理它。

Step by Step

第一步：安装 openai 库

在赫默的终端（Terminal）里运行这行命令：

# 终端执行
pip install openai

成功后会显示类似 Successfully installed openai-x.x.x。这个库把复杂的 API 调用细节封装成简单的 Python 函数，你不需要自己处理 HTTP 请求。

第二步：写代码

创建一个叫 hello_ai.py 的文件，输入以下内容：

# hello_ai.py
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的API密钥",          # ← 换成你自己的 API Key
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "用一句话介绍你自己"}
    ]
)

print(response.choices[0].message.content)
🔍 逐行解释：
  1. from openai import OpenAI — 导入安装好的工具包
  2. client = OpenAI(...) — 创建客户端，告诉程序「连接谁的服务器、用谁的密码」
  3. api_key — 你的身份凭证（去 DeepSeek 官网注册获取）
  4. base_url — DeepSeek API 的服务器地址
  5. client.chat.completions.create(...) — 发送请求给模型，让它生成回答
  6. model="deepseek-chat" — 指定用 DeepSeek 的聊天模型
  7. messages — 你要说的话（prompt），格式是 JSON 列表
  8. print(...) — 把模型返回的结果打印到屏幕上

第三步：运行

在终端里运行：

# 终端执行
python hello_ai.py

几秒钟后，你应该能看到模型打印出一段自我介绍。

理解返回的数据结构

你可能好奇：为什么代码里写的是 response.choices[0].message.content？

因为 API 返回的是一个结构化的 JSON 对象，像这样：

{
  "id": "chatcmpl-xxx",
  "choices": [
    {
      "message": {
        "content": "我是 DeepSeek，一个 AI 助手……"
      }
    }
  ]
}

所以 response.choices[0].message.content 就是「从返回结果里，取出第一条（索引0）选择里的消息内容」。这就是编程里常见的「从嵌套结构中取数据」。

🎁 你的第一个增量胜利

试试修改 content 里的问题，换成：

{"role": "user", "content": "帮我写一份项目周报的模板"}

运行后，AI 就会生成周报模板。换一个问题，AI 就换一个回答——你现在是在「编程式地用 AI」了，不再是在对话框里手动打字。

关键知识点

  • pip install — Python 的「应用商店」，装一次永久可用
  • Client — 一个连接器对象，负责你和 API 之间的通信
  • API Key — 你的身份凭证，必须保密
  • model 参数 — 指定用哪个模型（DeepSeek 有多个模型可选）
  • messages 格式 — 你发给模型的对话，是一个 JSON 列表，每条有 role 和 content
  • choices[0].message.content — 从返回结果中提取模型回复的文字

常见问题

Q: 报错 "ModuleNotFoundError: No module named 'openai'"
A: 忘记装库了，先运行 pip install openai

Q: 报错 "AuthenticationError" 或 "401"
A: API Key 填错了，检查是否有多余空格、引号是否正确

Q: 报错 "ConnectionError"
A: 网络问题，检查是否能访问 api.deepseek.com
