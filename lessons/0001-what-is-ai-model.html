📚 第 1 课 · 什么是 AI 模型？

2026-06-22 · 阅读约 5 分钟 · 术语表

一句话讲清

AI 模型是一个被训练来「预测下一个词」的程序。
你每次和赫默对话，背后就有一个 AI 模型在逐字生成回复。

对你有什么用？
你已经每天都在用 AI 模型了——只是通过赫默这个「外壳」。学会直接调用模型，你就能让 AI 帮你处理文件、批量生成报告、自动回复邮件，而不用手动一条条粘贴。

你平时用赫默，背后发生了什么？

假设你问赫默：「帮我写一封请假邮件」

  1. 你的消息 → 赫默把你的输入打包成 API 请求
  2. API 请求 → 发送到 AI 模型服务商（比如 DeepSeek 的服务器）
  3. 模型推理 → 模型根据你输入的每个字，逐字预测下一个最合适的字
  4. 生成结果 → 模型生成完回复，通过 API 返回给赫默
  5. 你看到回复 → 赫默把结果显示给你
💡 关键洞察：AI 模型本身只是一段程序 + 一堆参数（数字）。它没有「意识」，只是在做一道超级复杂的「下一个词填空」题。它之所以显得聪明，是因为它看过的文本量远超人类一生能读完的量。

核心概念

LLM（大语言模型）

Large Language Model。你用的 DeepSeek、ChatGPT、Claude 都是 LLM。特点是参数量极大（几十亿到几千亿），能理解和生成自然语言。

训练 vs 推理

  • 训练：给模型喂海量文本，让它学会语言规律（需要几周、几千块 GPU）
  • 推理：训练好后，你每次提问，模型跑一次计算给出答案（几秒内完成）

上下文窗口

模型一次能「看见」的最大文字量。比如 DeepSeek-V3 的上下文窗口是 128K token——约等于一本中等厚度的小说。你发给模型的所有历史对话都在这个窗口里。

你实际上在用什么模型？

赫默连接的是各种模型服务商。你用的可能是：

  • DeepSeek：国产模型，性价比极高，中文能力顶流
  • OpenAI（ChatGPT）：行业标杆，生态最完善
  • Anthropic（Claude）：长文本能力突出

本课程将以 DeepSeek 为主线，因为它是国内最能打的模型，价格低、中文好、API 简单。
