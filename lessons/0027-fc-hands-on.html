五分钟理解完整流程

Function Calling 的核心就是五步循环，跟第 10 课一样，但今天要写完整：

用户问 → AI 判断要不要工具 → AI 返回「工具名+参数」
↓
你的代码 实际执行工具 → 拿到结果
↓
把结果塞回给 AI → AI 组织自然语言回答

我们今天的目标是：把这五步写成一个完整的 Python 脚本，能跑起来。

第一步：准备工具函数

先写一个真的能查台区日电量的函数。这是你自己的业务，AI 不会这个，你来写：

# mock_data.py —— 模拟台区日电量数据
# 真实场景换成数据库查询或 Excel 读取
MOCK_METER_DATA = {
    "T07": {"2026-08-20": 1250.5, "2026-08-21": 1180.2, "2026-08-22": 1320.8},
    "T12": {"2026-08-20": 980.3,  "2026-08-21": 1020.1, "2026-08-22": 995.7 },
    "T25": {"2026-08-20": 2150.6, "2026-08-21": 2080.4, "2026-08-22": 2210.9},
}

def query_taigu_kwh(taigu_id, date):
    """查询某台区某日电量（kWh）"""
    data = MOCK_METER_DATA.get(taigu_id)
    if not data:
        return {"error": f"台区 {taigu_id} 不存在"}
    kwh = data.get(date)
    if kwh is None:
        return {"error": f"台区 {taigu_id} 在 {date} 无数据"}
    return {"taigu_id": taigu_id, "date": date, "kwh": kwh}

这是个普通的 Python 函数，没有 AI 任何事。这就是工具的本质——就是一个函数，AI 帮你决定「什么时候调」。

第二步：写工具「说明书」

要让 AI 知道这个函数能调，得写一份工具描述。AI 全靠这段文字判断「该不该调、传什么参数」：

tools = [
    {
        "type": "function",
        "function": {
            "name": "query_taigu_kwh",
            "description": "查询指定台区在某一天的电量（kWh）。当用户问某个台区某天的用电量时使用。",
            "parameters": {
                "type": "object",
                "properties": {
                    "taigu_id": {
                        "type": "string",
                        "description": "台区编号，如 T07、T12"
                    },
                    "date": {
                        "type": "string",
                        "description": "日期，格式 YYYY-MM-DD"
                    }
                },
                "required": ["taigu_id", "date"]
            }
        }
    }
]
💡 「description」是最关键的部分：AI 不会读你的函数名或代码，它只看 description 决定要不要调。写「查询指定台区在某一天的电量」比写「查电」清晰 10 倍。

第三步：完整脚本（从发消息到拿回答）

把上面所有部分串起来，这是完整的最小可用 Agent：

# agent_fc_demo.py
import json
from openai import OpenAI
from mock_data import query_taigu_kwh

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://api.deepseek.com"
)

# 工具说明书（精简版）
tools = [{
    "type": "function",
    "function": {
        "name": "query_taigu_kwh",
        "description": "查询台区某日电量（kWh）",
        "parameters": {
            "type": "object",
            "properties": {
                "taigu_id": {"type": "string", "description": "台区编号，如 T07"},
                "date":    {"type": "string", "description": "日期 YYYY-MM-DD"}
            },
            "required": ["taigu_id", "date"]
        }
    }
}]

def run_agent(user_query):
    messages = [{"role": "user", "content": user_query}]

    # 第 1 次调用：让 AI 决定要不要调工具
    response = client.chat.completions.create(
        model="deepseek-chat",
        messages=messages,
        tools=tools
    )
    msg = response.choices[0].message

    # 如果 AI 不想调工具，直接返回它的回答
    if not msg.tool_calls:
        return msg.content

    # AI 想调工具：执行它，把结果喂回去
    tool_call = msg.tool_calls[0]
    args = json.loads(tool_call.function.arguments)
    print(f"→ AI 决定调用 {tool_call.function.name}({args})")

    # ← 这里是你真正在工作的代码
    tool_result = query_taigu_kwh(args["taigu_id"], args["date"])

    # 第 2 次调用：把工具结果喂给 AI，让它组织自然语言回答
    messages.append(msg)
    messages.append({
        "role": "tool",
        "tool_call_id": tool_call.id,
        "content": json.dumps(tool_result, ensure_ascii=False)
    })
    final = client.chat.completions.create(
        model="deepseek-chat",
        messages=messages
    )
    return final.choices[0].message.content

if __name__ == "__main__":
    print(run_agent("T07 台区 8 月 22 号用了多少度电？"))

这段代码 ~60 行，跑出来就是你的第一个最小可用 Agent。

第四步：跑起来看效果

把上面两段代码（mock_data.py 和 agent_fc_demo.py）保存到同一目录，pip install openai 装好依赖，然后：

$ python agent_fc_demo.py
→ AI 决定调用 query_taigu_kwh({'taigu_id': 'T07', 'date': '2026-08-22'})
T07 台区在 2026-08-22 用电 1320.8 kWh。

看到没？AI 看到「T07 台区 8 月 22 号用了多少度电」这句话，自己判断要调 query_taigu_kwh，自己从中文里提取出了 taigu_id="T07" 和 date="2026-08-22"，你完全没写 if-else 解析用户问什么。

💡 你的第一个 Agent 跑起来了：用户问 → AI 决定调工具 → 你的代码执行 → AI 组织回答。这和赫默 agent 帮你查文件、调 API 是同一套机制，只不过这次是你自己写的。

第五步：试一试故意刁难 AI

改几个用户输入，看 AI 怎么反应。拷几个到代码里跑：

  • 「T07 上周五多少度电？」—— AI 得自己换算「上周五 = 2026-08-22」
  • 「今天天气怎么样？」—— AI 看到没相关工具，应该直接用文本回答，不调工具
  • 「T99 昨天多少度电？」—— 工具会返回 {"error": "台区 T99 不存在"}，AI 得优雅告诉用户

这三个测试就是 Function Calling 的基础健壮性检查。第 35 课（评估与安全）会专门讲怎么系统化做这件事。
