## 关键设计点

- **`--selftest` 不需要 key**：验证的是数据层口径，与模型无关。把「工具算得对」和「模型说得对」两件事分开验——这个顺序本身就是工程判断力（课程明确点出）
- **前置知识零新增**：本课刻意不引入任何新概念，全部是已学零件 → 符合「毕业项目不是新课」的定位，也降低了用户的启动阻力
- **与 43 课的关系**：37 是 v1（可展示可部署最小完整形态），43 是求职作品主体（P6 完整版）。明写在课件里，避免用户以为 37 做完了就结束
