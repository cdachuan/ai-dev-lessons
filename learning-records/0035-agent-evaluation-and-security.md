## 核心内容

1. **评估三要素**：固定测试集 EVAL_SET + 金标准答案 golden（实跑 pandas 算出）+ 判分器 judge()，纯代码可复现
2. **评估驱动开发**：改代码前后各跑一遍，PASS 数涨跌 = 改对改错。不接真 LLM 也能先跑框架（simulate_answer 占位，接真模型时只换这一层，考卷/判分器不动）
3. **四道评估题覆盖四考点**：工具选择 / 口径正确性 / 口径澄清 / 失败场景
4. **安全四道闸**：① API key 环境变量 ② 输入边界 ③ 危险操作确认 ④ 成本记录（token 上限）

## 关键设计点

- **评估框架是纯代码**：不依赖真 LLM，改模型不改考卷——这是评估台的复用价值（43 课「可演示」的底气）
- **裸奔 Agent 死法暴露**：第③④题都是口径问题，量化成 FAIL 才看得见要补哪
- **「确定」不是问出来的，是拿固定考卷反复跑出来的**
