## 关键收获

1. **openpyxl 是读取 Excel 的标配库** —— `pip install openpyxl` 安装后，用 `load_workbook()` 加载文件，`sheet.iter_rows()` 逐行读取。这个模式可以处理任何 Excel 表格。

2. **for 循环的实战应用** —— 之前只在理论知识中提到的 `for` 循环，今天第一次在代码中落地。`for row in sheet.iter_rows(...)` 的意思是「对于 Excel 里的每一行，做同一件事」。这是编程中最核心的思维模式之一。

3. **Excel 到 AI 的「翻译」模式** —— 表格数据不能直接发给 AI，需要先转成自然语言描述。`" | ".join()` 拼接法把每一行变成一段文字，让 AI 能「读懂」表格结构。这个「结构化数据 → 文字」的转换思路可以推广到 JSON、CSV、数据库等任何数据源。

4. **「换 prompt 不改代码」的灵活性** —— 脚本一次写好，通过修改 system prompt 里的模板，可以产生完全不同的输出（风险清单、人员负荷表、跨语言翻译）。这是第 11 课「模板化输出」思路的延展。
