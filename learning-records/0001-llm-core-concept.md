# 0001 · LLM 核心概念认知

**日期**：2026-06-22
**课程**：0001 · 什么是 AI 模型？
**状态**：已交付

## 关键洞察

1. **AI 模型的本质是做「下一个词填空」** —— 它不是真的有意识，而是根据海量文本训练出的统计规律来逐词预测。这个认知能破除对 AI 的「神秘感」，把它理解为工具而非魔法。

2. **用户已经每天在用模型了 —— 只是隔着赫默这层壳**。课程的增量在于：从「用别人搭好的工具」进阶到「自己直接调用模型」。后者能解锁批处理、自动化等场景。

3. **训练（几周/几千张 GPU）和推理（几秒）是两个完全不同的阶段**。用户只需要关心推理阶段——也就是调用 API。

4. **上下文窗口决定了模型一次能处理多少信息**。这是后续理解 prompt 工程、agent 记忆等概念的基础。
