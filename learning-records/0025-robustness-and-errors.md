- **日期**：2026-08-20

- **类型**：实践课
- **状态**：done（用户答对小测确认学完）

## 推送内容

- **核心认知**：demo 能跑 ≠ 工具能用
  - 真实世界里文件路径会错、API 会抖、CSV 列名会带空格——这些不是 bug，是常态
  - 脚本必须能应对，否则只是 demo
- **try/except 三件套**：保护程序不崩
  - 文件错误（路径不对）→ 提示用户检查路径
  - API 错误（超时/限流）→ 重试或降级
  - 数据错误（列名错/缺失值）→ 先清洗再算
- **重试机制**：API 调失败后等几秒再试，最多 3 次，全失败返回 None 交给调用方决定
- **日志**：print 加时间戳，一眼看出跑挂在哪一步（读数据/清洗/调API/出结果）
- **关键认知升级**：新手以为写了 try/except 就安全，老手知道「每种错误该怎么处理」才是真正要想的事

## 小测

分析脚本报错 `KeyError: '用电量'`，最可能的原因？
- A. Python 版本太低
- B. CSV 里这列名字不是「用电量」，可能是「电量」或带空格
- C. pandas 没装
- D. 电脑内存不够

正确答案 **B**。KeyError 十有八九是列名不匹配（列名带空格/名字不同），.str.strip() 清洗 + 打印实际列名排查最有效。
