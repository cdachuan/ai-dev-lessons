## 关键收获

1. **`sys.argv` 是脚本接受「外来参数」的入口** —— `sys.argv[0]` 是脚本名，`sys.argv[1]` 是第一个命令行参数。这解决了之前脚本的「文件路径写死」问题，让一个脚本处理任意文件。

2. **System Prompt 第一次在代码中落地** —— 第 7 课学的概念（system prompt 设定角色和规则）今天变成了实际的代码。`messages = [system_msg, user_msg]` 的结构是后续所有 AI 脚本的基础模板。

3. **「模板化输出」是 AI 脚本的关键设计模式** —— 不满足于让 AI 自由发挥，而是用 system prompt 规定输出格式（今日完成/明日计划/待跟进）。这让 AI 的输出可直接复制使用，无需人工二次调整。

4. **从「写一次用一次」到「写一次用多次」** —— 命令行参数让脚本从一次性工具升级为可重复使用的「命令」。这是自动化思维的一个关键跳跃。
