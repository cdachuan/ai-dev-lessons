## 关键洞察

1. **Token 是 LLM 的「计量单位」** —— 模型不读「字」，读「Token」。一句话被拆成若干 Token，中文大约 1 个字 ≈ 1-2 个 Token，英文 1 个词 ≈ 1 个 Token。这是理解「为什么 API 按 Token 收费」的基础。

2. **Token 两头花钱：输入 + 输出** —— 每次 API 调用收两笔费：你发给模型的 prompt（输入 Token）+ 模型返回的回答（输出 Token）。输出通常比输入贵 2-4 倍，因为生成过程需要更多计算。

3. **上下文窗口 = 最大 Token 数** —— 模型的上下文窗口（如 64K/128K）限制了单次能处理的信息量。超过会被截断或压缩。理解 Token 后，就能解释为什么「把整本书塞进 prompt」行不通。

4. **Token 和成本是直接挂钩的** —— 用户每天用 Hermes 聊天时底层就在消耗 Token。理解了 Token 就理解了为什么需要控制 prompt 长度、为什么需要压缩、为什么切廉价模型能省钱。
