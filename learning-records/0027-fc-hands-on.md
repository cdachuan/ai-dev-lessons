## 核心内容

1. **回顾 5 步循环**：用户问 → AI 判断 → 返回工具名+参数 → 你的代码执行 → 把结果喂回 AI
2. **写一个真实业务函数**：`query_taigu_kwh(taigu_id, date)`，模拟台区日电量查询
3. **写工具说明书**：name / description / parameters 三件套，description 是 AI 决策的关键
4. **完整 60 行脚本**：`agent_fc_demo.py`，从发消息到拿回答
5. **三个边界测试**：时间换算、无关问题、不存在数据

## 关键设计点

- **description 是命门**：AI 不读你的函数名和代码，只看 description 决定要不要调、写"查询指定台区在某一天的电量（kWh）"比"查电"清晰 10 倍
- **执行归代码，决策归 AI**：第 10 课就讲过，今天亲手写一遍
- **最小可用 Agent = 60 行**：不是 200 行，是 60 行
