# 0003 · 第一次用 Python 调 DeepSeek API

**日期**：2026-07-01
**课程**：0003 · Hello World — 用 Python 调一次 DeepSeek API
**状态**：已交付

## 关键洞察

1. **「编程式调用」vs 「对话框使用」是思维转折点** — 用户之前用赫默是「手动打字→等回复」，现在第一次体验「写代码→运行→机器自动调用」。这个转变是后续自动化的基础。需要强调：同样的代码可以跑一万次，而手动操作不行。

2. **三层结构要拆解**：
   - 安装工具（`pip install openai`）— 一次性的准备工作
   - 配置客户端（API Key + base_url）— 连接谁、你是谁
   - 发送请求（messages 格式）— 你要说什么
   
   用户编程基础弱，这三层不能混在一起讲，必须分步骤。

3. **JSON 格式是隐形门槛** — `{"role": "user", "content": "xxx"}` 这个结构对程序员来说是常识，但对新手可能看起来像天书。需要明确解释「这是 API 规定的对话格式，每条消息有角色（谁说的）和内容（说了什么）」。

4. **response.choices[0].message.content 是「取数据」的典型模式** — 这是新手第一次接触「从嵌套结构取值」。虽然不用深入讲 JSON，但可以用「一层层剥开」的比喻帮助理解。

## 待观察

- 用户是否能独立完成注册 API Key + 安装 + 运行的全流程
- 用户对「写代码」这件事的畏难程度 — 如果是实操课，需要更详细的引导
- JSON 格式是否被正确理解，还是只是「照抄」
