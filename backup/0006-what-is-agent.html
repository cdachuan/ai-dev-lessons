第 6 课 · 什么是 Agent？

2026-06-28 · 阅读时间：5 分钟

你已经和赫默聊了很久了。你有没有想过——当你对赫默说「帮我查一下某某网站」或者「帮我整理这个文件」，赫默是怎么做到的？

一个普通的 LLM（像你第 1 课学到的）只会生成文字。它不能搜索网页、不能读取文件、不能运行代码。但赫默可以。为什么？

💡 一句话 Agent（智能体、代理） = LLM（大脑）+ 工具（手脚）+ 自主决策（何时用哪个工具）。

LLM 与 Agent 的区别

普通 LLMAgent
能力只能聊天/生成文字能搜索、读文件、跑代码、操作应用
决策你问什么答什么自己判断「是否需要工具」「用哪个工具」
流程一问一答多步循环：想→做→看结果→再想
例子ChatGPT 纯聊天赫默、Claude Code、AutoGPT

Agent 的核心工作流

Agent 不是一次性回答，而是「循环」工作：

🧠 收到你的问题 → 🤔 判断需要什么工具 → 🔧 调用工具 → 📥 得到结果 → 🧠 判断够不够 → 📤 给你最终答案

用你熟悉的例子——你在赫默说「帮我翻译这份文件」：

  1. 🧠 判断：赫默看到你说的是「文件」，决定调用「读文件」工具
  2. 🔧 调用：赫默执行读文件操作，拿到文件内容
  3. 📥 得到结果：看到了文件里的文字
  4. 🤔 再判断：够了吗？还需要更多工具吗？好，直接翻译就够了
  5. 📤 输出：把翻译好的内容回复给你

这一切发生在几秒之内，你看到的是最终结果。但背后其实跑了一整个「思考→行动→观察→再思考」的循环。

为什么这很重要？

理解 Agent 的原理，你就明白了为什么赫默「不只是个聊天机器人」——它是一个能自主完成任务的系统。这对你的目标（用 AI 解决实际工作问题）至关重要，因为：

  • ✅ 你可以让 Agent 帮你做多步骤任务（比如：读邮件→提取待办→写进表格）
  • ✅ 你也可以自己写一个简单的 Agent（用你第 3 课学到的方法调 API，再加几行判断逻辑）
  • ✅ 你能理解为什么 Agent 有时候会「卡住」或「犯错」（工具返回的结果不如预期 → 决策出错）

最简单的 Agent 代码

下面是一个极简版的 Agent 代码，展示了「判断→调用工具→再判断」的模式。你不需要完全看懂每一行，重点看结构：

# 极简 Agent 示例 — 理解即可，不用自己打
def search_web(query):
    """假装搜索了一下"""
    return f"搜索结果：关于「{query}」有很多资料..."

def ask_llm(messages):
    """假装调用了 LLM"""
    last = messages[-1]["content"]
    if "搜索" in last or "查一下" in last:
        return {"role": "assistant", "content": search_web(last)}
    return {"role": "assistant", "content": f"你说的是：{last}"}

def simple_agent(user_input):
    """Agent 主循环"""
    messages = [{"role": "user", "content": user_input}]
    
    # 第 1 步：问 LLM
    reply = ask_llm(messages)
    
    # 第 2 步：如果 LLM 决定用工具
    if reply["content"].startswith("搜索结果"):
        # 把工具结果放回对话
        messages.append(reply)
        messages.append({
            "role": "user",
            "content": "请基于搜索结果回答问题"
        })
        # 第 3 步：再次问 LLM
        final = ask_llm(messages)
        return final["content"]
    
    return reply["content"]

# 用一下
print(simple_agent("帮我查一下今天天气"))
# 输出：搜索结果：关于「帮我查一下今天天气」有很多资料...
🧑‍🏫 看懂了吗？

真正的 Agent（赫默、Claude Code）比这个复杂得多，但核心逻辑一模一样：收到任务 → 调用工具 → 处理结果 → 再决定。你看到的「自动读写文件」「搜索网页」都是这个循环在驱动。

三个关键术语

术语意思
Agent能自主使用工具、规划步骤、执行多步任务的 AI 系统
工具（Tool）Agent 可以调用的外部能力，比如搜索、读文件、运行代码
Agent 循环观察→思考→行动→观察→思考→行动…直到完成任务

小节测验

❓ Agent 和普通 LLM 最大的区别是什么？

A. Agent 的模型参数更大
B. Agent 能自主决定是否调用工具，并多步执行任务
C. Agent 只有大公司才能用
D. Agent 不需要 prompt

✅ 答案：B。普通 LLM 只能一问一答；Agent 能自主决定「要不要用工具」「用什么工具」「下一步做什么」，循环执行直到完成任务。
