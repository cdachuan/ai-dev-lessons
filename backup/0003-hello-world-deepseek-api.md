# 0003 · 首次 DeepSeek API 调用

**状态**：已交付

## 关键洞察

1. **把抽象变成可执行** —— 前两课讲了「模型」和「API」的概念，但概念停留在脑子里。这一课让用户亲手跑通一次 API 调用，把「模型会响应我的 prompt」从抽象概念变成可观察的事实。

2. **代码量极少，认知门槛低** —— 核心代码不到 10 行（算上 import 和 print）。用户不需要懂 Python 细节，只需理解 5 个参数的含义（api_key / base_url / model / messages / print），就能跑起来。

3. **深层类比：赫默 = API 客户端** —— 用户每天用赫默聊天，本质也是调 API。这个对应关系在实操后变得具体：`messages` 参数 = 聊天输入框的内容，`print` 输出 = 赫默的回复。用户会发现「原来自己一直在用 API，只是隔了层 UI」。

4. **正确对待 API Key 的安全意识** —— 用户编程基础弱，可能习惯性地把密钥贴到公开地方。需要在本课明确强调「密钥 = 密码」，并给出 Git 安全提示。

5. **「改一句话就能做不同任务」的开箱感** —— 替换 `content` 内容即可让模型做不同事。这个「参数化」思维是后续工程化（写函数、做批处理）的起点。

## 待观察
