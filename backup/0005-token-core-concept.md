# 0005 · Token 核心概念

**日期**：2026-06-27
**课程**：0005 · 什么是 Token？
**状态**：已交付

## 关键洞察

1. **Token 是计费和记忆的统一度量**——这是本课最核心的认知。用户可能以为「费用」和「AI 记性」是两回事，但它们背后都是 token。prompt_tokens + completion_tokens = 费用；total_tokens 逼近 context_window 上限 = AI 开始「忘事」。一石二鸟的概念锚点。

2. **「token ≠ 字」的认知纠正**——中文用户容易直觉认为 1 汉字 = 1 token，但实际上 tokenizer 按子词（subword）切分，常见词可能 2-3 个汉字才 1 token，生僻字可能 1 字多 token。这个纠正很关键，否则用户会误判费用和上下文用量。

3. **usage 对象是「账单明细」**——代码中 response.usage 是一个小而具体的 API 知识点，用户学完就知道每次调用后怎么查 token 消耗。这是 API 编程必备的调试技能。

4. **为什么聊久了 AI 会「断片」**——对话历史 token 累积 → 超过上下文窗口。这个解释把抽象概念和用户日常体验联系起来，增强理解和记忆。
