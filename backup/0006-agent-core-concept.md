# 0006 · Agent 核心概念

**日期**：2026-06-28
**课程**：0006 · 什么是 Agent？
**状态**：已交付

## 关键洞察

1. **「LLM 只能聊天，Agent 才能做事」**——这是本课最核心的认知跳跃。用户之前可能以为赫默的所有能力都是「模型自带的」，但实际上模型只会生成文字。搜索、读文件、跑代码这些能力是「工具」提供的，模型只负责判断何时用哪个工具。这个区分是整个 AI 工程化链条的起点。

2. **Agent 循环（Think → Act → Observe）是核心模式**——Agent 不是一次性回答，而是一个循环：收到问题 → 判断 → 调工具 → 得结果 → 再判断 → 最终输出。这个模式在后面所有课（Tool Calling、RAG、Function Calling）里都会反复出现。把循环建立起来，后续概念就有了容器。

3. **用户每天用的赫默就是一个 Agent**——这可能是最有力量的认知锚点。用户已经熟练使用赫默，但不理解「为什么赫默能做这么多事」。把赫默的日常行为映射到 Agent 循环中，抽象概念立刻变具体。用户下次用赫默时，就能在脑子里「看到」背后发生了什么。

4. **简单代码示例能破除神秘感**——即使是伪代码级别的 agent 循环，也能让用户意识到「Agent 不是什么黑魔法，就是函数调用 + 条件判断」。这对后续写真实脚本（0008）有铺垫作用。

## 待观察

- 用户可能会问「那我自己能写一个赫默吗？」——这个问题很好，但需要到 0010 Function Calling 之后才能真正回答
- 是否需要补充「Agent ≠ 全自动」，Agent 也会犯错，需要人工监督
- 术语表里预填了 Agent、Tool Calling、RAG、Function Calling，但用户还没学到后三个——设计课程时要注意顺序依赖
