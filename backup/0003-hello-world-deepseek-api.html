第 3 课 · Hello World — 用 Python 调一次 DeepSeek API

🎯 本课目标：写一段不到 10 行的 Python 代码，让 DeepSeek 模型帮你回答一个问题。

为什么这很关键？

前两课你知道了「模型是什么」和「API 是什么」。今天是第一次亲手调用 API——完成后你会发现：你在赫默里做的每一次对话，本质上和这段代码做的事是一样的。

增量胜利 ⚡：学完这课，你就能让任何 Python 脚本「开口说话」——自动写邮件、批量总结文档、每天定时问 AI 问题……

你需要什么

  • 一台电脑（你就有）
  • Python 3.11+（你已经装了）
  • DeepSeek API Key（密钥，去这里免费申请）
⚠️ API Key 是密码级别的敏感信息——不要发到群里、不要上传到 GitHub、不要截图发给任何人。谁拿到它，谁就能用你的额度调用模型。

第一步：装一个库

DeepSeek 的 API 用的是 OpenAI 兼容协议，所以我们可以用 openai 这个 Python 库来调它。

在终端（Terminal）里运行：

pip install openai

等几秒，看到提示 Successfully installed openai-xxx 就装好了。

第二步：写代码

新建一个文件 hello_ai.py，把下面这段复制进去：

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",   # ← 把这里换成真的密钥
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "用一句话介绍你自己"}
    ]
)

print(response.choices[0].message.content)

第三步：运行

终端运行：

python hello_ai.py

你会看到类似这样的输出：

我是 DeepSeek，一个由深度求索公司开发的大型语言模型，专注于理解和生成自然语言文本，帮助你解答问题和处理信息。

👏 恭喜！你刚刚完成了第一次 API 调用。

这段代码在做什么？

逐行拆解：

1from openai import OpenAI —— 导入我们刚装的库
2-5client = OpenAI(...) —— 创建客户端，告诉代码「找谁说话」（base_url）和「你的密码」（api_key）
6-11response = client.chat.completions.create(...) —— 发送请求，就像你在赫默输入框敲回车
7model="deepseek-chat" —— 指定用哪个模型（DeepSeek 最新版）
8-10messages=[...] —— 你的 prompt（输入消息）
13print(...) —— 把模型的答复打印到屏幕上

更实用一点

把 content 换成你真正想问的问题试试：

messages=[
    {"role": "user", "content": "用中文写一封会议提醒邮件，主题是项目周报，时间周五下午3点"}
]

再运行一次——模型就帮你起草了一封邮件。

❓ 小测：以下哪一步是「告诉代码该找哪个网址的 API」？

A. api_key="..."
B. base_url="https://api.deepseek.com/v1"
C. model="deepseek-chat"
D. messages=[...]

查看答案

正确答案是 B。base_url 指定 API 的地址，api_key 是密码，model 选模型，messages 是输入内容。

如果出错了？

  • ModuleNotFoundError → 你还没运行 pip install openai，或装在了另一个 Python 环境
  • AuthenticationError → API Key 填错了或还没申请
  • ConnectionError → 网络问题，检查能否访问 api.deepseek.com

如果解决不了，把报错信息发给赫默 agent，它能帮你分析。

本课总结

  • 调 API = 装一个库 + 写几行代码 + 跑起来
  • API Key 是你的「密码」，务必保密
  • messages 里放的就是你的 prompt，和你在赫默里说的一样
  • 把 content 换成不同任务，就能让 AI 做不同的事
