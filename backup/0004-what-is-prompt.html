Prompt 是什么？

Prompt（提示词/提示语）就是你给 AI 模型的输入指令——你说什么、问什么、要求什么，那整段话就是 prompt。

上一课（第 3 课）的代码里，messages 参数里的 "content": "用一句话解释什么是量子计算"——这里面的中文内容，就是一个 prompt。

生活中的类比：你给下属布置任务时说的那段话就是 prompt。说清楚→做好；说模糊→做偏。AI 也一样。

Prompt 的两个层级

在代码里，messages 是一个列表（list），可以放多条消息。最常见的两种角色：

角色作用类比
system 给 AI 设定身份、规则、约束（只对对话生效一次） 「你是我的项目助理，回复不超过 200 字」
user 你当前的具体问题/任务（每次对话都可以不同） 「整理这个会议的要点」
💡 举个例子： 
messages = [
    {"role": "system", "content": "你是一个耐心的老师，用小学五年级能听懂的话解释概念。"},
    {"role": "user",    "content": "什么是区块链？"}
]
加上 system prompt 之后，AI 的回复会明显更简单、更口语化。试试看。

一句好 Prompt 的三个要素

  1. 明确目标——你想要什么结果？「总结这篇文章」vs「用三句话总结这篇文章的核心观点」
  2. 提供上下文——AI 没有默认背景知识。你给它越多相关背景，答案越准
  3. 指定格式——想要清单、表格、段落、还是 Markdown？直接说

坏 Prompt vs 好 Prompt

❌ 坏 Prompt✅ 好 Prompt
「帮我写个方案」「帮我写一份 500 字的项目推广方案，目标受众是中小企业老板，语气专业但有温度」
「这个数据怎么说」「我手上有 3 月份销售额 120 万，比 2 月涨了 15%。请写一段话给老板汇报，突出增长、不提绝对值」

你今天学到的「增量胜利」🥇

学完这课后，你能做一件以前做不到的事：

在赫默（或其他 AI 工具）里，有意识地写出 system prompt + user prompt 的结构，让 AI 的输出质量明显提升。不再是「瞎问瞎答」，而是「精准指挥」。
